# com.agy.runtime

## Overview
Coordinates runtime lifecycle, asset installation, environment wiring, and shell/hardware bridges for the embedded Antigravity core. Exposes build configuration and app-private path resolution (`RuntimeConfig`, `RuntimePaths`), orchestrates Phase 1 fail-closed core/web extraction with manifest SHA-256 verification (`CoreInstaller`, `ManifestVerifier`) and Phase 2 asynchronous Bionic toolchain/seed-package setup (`EnvInstallScheduler`), manages live DNS/hosts configuration (`NetworkConfigWriter`, `NetworkMonitorHolder`), seeds onboarding state, MCP server configs, and bundled skills (`OnboardingSeeder`), generates POSIX/Bionic bridge and URL/torch shim scripts under `runtime/bin` (`ShellBridgeInstaller`), exposes Camera2 flashlight control (`TorchReceiver`), and binds runtime coordination behind `RuntimeManager`.

## Invariants
- `CoreInstaller.installCore` is fail-closed: it throws `IllegalStateException` if unpacking `RuntimePaths.RUNTIME_ASSET` fails, if `ManifestVerifier.verifyError` returns non-null, or if unpacking `RuntimePaths.WEB_ASSET` fails; runtime wipe refuses paths outside `<filesDir>/` or intersecting `<filesDir>/.gemini` via canonical path checks `[CoreInstaller.java:installCore]` `[CoreInstaller.java:assertSafeToWipe]`.
- Phase 1 install executes in strict order: runtime wipe (when manifest SHA-256 or required binaries `liblanguage_server.so`, `libloader.so`, `liblse_compat.so` are stale/missing) -> unpack -> recursive chmod (`bin` & `lib`) -> `ManifestVerifier.verifyError` -> write `.installed` -> conditional web unpack (refreshed if `.web_installed` is older than `packageInfo.lastUpdateTime` or `web/generated/main.js` is missing) -> `writeNetworkConfig` -> `startNetworkMonitor` -> `OnboardingSeeder.seed` -> `ShellBridgeInstaller.install(rm)` in one pass when `EnvInstaller.isInstalled(ctx)` is `true`, otherwise `installFallbackBridges` & `installOpenUrlShims` `[CoreInstaller.java:installCore]` `[CoreInstaller.java:isRuntimeUpToDate]` `[CoreInstaller.java:isWebExtracted]`.
- `ManifestVerifier.verifyError` is fail-closed (returning `"manifest unreadable: ..."` on error), supports nested `{"files": {...}}` or flat `{path: sha256}` JSON, skips keys ending in `"manifest.json"`, checks only `isFile() && length() > 0` for `liblanguage_server.so` / `RuntimePaths.CORE_NAME`, and enforces case-insensitive SHA-256 equality for all other entries `[ManifestVerifier.java:verifyError]`.
- `EnvInstallScheduler.schedule` enforces single-flight via `started.compareAndSet(false, true)`, resets `started.set(false)` on any `Throwable` so retries remain possible, guarantees `"nodejs"` is present in the seed package list unless `"nodejs"` or `"nodejs-lts"` is already listed, and runs `EnvInstaller.install` -> `EnvBundleManifest.load` -> `SeedPackageInstaller.installDefaults` -> `ShellBridgeInstaller.install(rm, fresh || seeded)` `[EnvInstallScheduler.java:schedule]`.
- `NetworkConfigWriter.write` is `synchronized`, aborts without writing either file if `<filesDir>/etc` cannot be created, caches `lastResolvContent` to skip redundant `resolv.conf` rewrites when unchanged, and writes `hosts` only when absent or empty; `NetworkMonitorHolder` retains only application `Context`, debounces network-change DNS syncs by `500` ms on a daemon `ScheduledExecutorService` (`AgyDnsSync`), serializes `start()`/`unregister()`, and tolerates repeated/null `unregister()` `[NetworkConfigWriter.java:write]` `[NetworkMonitorHolder.java:NetworkMonitorHolder]` `[NetworkMonitorHolder.java:scheduleDnsWrite]`.
- `OnboardingSeeder.seed` catches all top-level exceptions so onboarding never blocks startup, skips existing non-empty state/skill/project files, resolves one shared `installation_uuid` from `jetski_state.pbtxt` or `antigravity_state.pbtxt` (ignoring `TEMPLATE_INSTALL_UUID`, defaulting to a random UUID), leaves invalid `mcp_config.json` files and user-customized MCP commands untouched, and deduplicates up to three config/skill roots (`<projects>/..`, `<appData>`, `<appData>/../antigravity`) `[OnboardingSeeder.java:seed]` `[OnboardingSeeder.java:seedStateFile]` `[OnboardingSeeder.java:resolveInstallationUuid]` `[OnboardingSeeder.java:mergeBundledMcpServers]` `[OnboardingSeeder.java:seedMcpConfigs]` `[OnboardingSeeder.java:seedSkills]`.
- `RuntimeConfig.httpsPort` always falls back to `DEFAULT_HTTPS_PORT` on null `Context`, missing `https_server_port` resource, or exception; `RuntimePaths` anchors all paths under `appContext.getFilesDir()` `[RuntimeConfig.java:httpsPort]` `[RuntimePaths.java:RuntimePaths]`.
- `RuntimeManager` generates one immutable UUID `csrfToken` per instance, serializes `installCore()`, `refreshNetwork()`, and `writeNetworkConfig()` via instance synchronization, updates DNS in place in `refreshNetwork()` without restarting the core, and fails closed in `coreCommand()` if `libloader.so` or `liblanguage_server.so` is absent (adding `--preload liblse_compat.so` only if `lseCompat.isFile()` and cached `isNativeLseSupported()` / `cpuSupportsAllEmulatedFeatures` detects any of `atomics`, `asimddp`, `asimdrdm`, `fcma`, `lrcpc`, `ilrcpc` missing from `/proc/cpuinfo`) `[RuntimeManager.java:RuntimeManager]` `[RuntimeManager.java:coreCommand]` `[RuntimeManager.java:cpuSupportsAllEmulatedFeatures]` `[RuntimeManager.java:isNativeLseSupported]` `[RuntimeManager.java:refreshNetwork]`.
- All public `ShellBridgeInstaller` methods serialize on `ShellBridgeInstaller.class`; `install` materializes fallback bridges (passing `force || !new File(bin, BRIDGE_MARKER).isFile()` to skip `normalizeRuntimeBinScripts` on warm starts) and `OPEN_URL_SHIMS` before checking `$PREFIX/bin/bash`, never overwrites existing fallback `bash`/`sh` in `installFallbackBridges`, `writeScript` skips rewriting/chmodding when an executable file with matching length and bytes already exists, skips `rish`, `node`, `agy-mcp-android`, `agy-mcp-browser`, `python3`, `python`, and all 9 `OPEN_URL_SHIMS` during bulk bridge generation, skips bulk regeneration when `!force` and `.agy-bridges` matches `BRIDGE_FORMAT` (`6`), prefix path, and `$PREFIX/bin` regular-file count, and normalizes CRLF only in `#!` text files sized `4..1 MiB` `[ShellBridgeInstaller.java:install]` `[ShellBridgeInstaller.java:installFallbackBridges]` `[ShellBridgeInstaller.java:writeScript]` `[ShellBridgeInstaller.java:OPEN_URL_SHIMS]` `[ShellBridgeInstaller.java:BRIDGE_FORMAT]` `[ShellBridgeInstaller.java:markerMatches]` `[ShellBridgeInstaller.java:normalizeRuntimeBinScripts]`.
- Generated Bionic bridge scripts quote paths via `ShellQuote.quote`, set Bionic `LD_LIBRARY_PATH` and conditional `LD_PRELOAD`, strip `netdns=go` from `GODEBUG`, coordinate on-demand Node.js bootstrap via `$HOME_DIR/logs/.node-bootstrap.lock` (15s `pkg` wait, 120s concurrent waiter timeout, stale dead-PID eviction), and wait up to 10s in MCP/Python bridges; generated `OPEN_URL_SHIMS` clear `LD_PRELOAD`/`LD_LIBRARY_PATH` and target the app package explicitly `[ShellBridgeInstaller.java:writeBridge]` `[ShellBridgeInstaller.java:writeNodeBridge]` `[ShellBridgeInstaller.java:writeExecBridge]` `[ShellBridgeInstaller.java:appendStripGodebugNetdnsGo]` `[ShellBridgeInstaller.java:writeOpenUrlShim]`.
- `TorchReceiver.onReceive` ignores null intents and actions other than `"com.agy.ACTION_TORCH"`, defaults `enabled` to `true` unless overridden by `state` (`off`/`0`/`false` vs `on`/`1`/`true`), and `setTorchMode` requires `API >= M` and toggles the first camera with `FLASH_INFO_AVAILABLE == true`, catching all `Throwable`s `[TorchReceiver.java:onReceive]` `[TorchReceiver.java:setTorchMode]`.

## Side Effects
- Recursively deletes `runtime/` when stale, unpacks `assets/runtime` and `assets/web`, recursively sets readable+executable permissions on `runtime/bin` and `runtime/lib`, reads/hashes extracted runtime files, and atomically writes `.installed` and `.web_installed` markers `[CoreInstaller.java:wipe]` `[CoreInstaller.java:installCore]` `[CoreInstaller.java:writeMarker]` `[ManifestVerifier.java:verifyError]`.
- Spawns daemon thread `"EnvInstallThread"`, mutates the caller's `AtomicBoolean`, runs Bionic prefix installation (`EnvInstaller.install`), installs default seed packages (`SeedPackageInstaller.installDefaults`), and regenerates shell bridges `[EnvInstallScheduler.java:schedule]` `[RuntimeManager.java:installEnvInBackground]`.
- Creates `<filesDir>/etc`, queries system DNS via `DnsCollector.collectDnsServers`, atomically writes `etc/resolv.conf` and `etc/hosts`, registers/unregisters Android `NetworkMonitor` callbacks, and mutates `ProcessBuilder` environment maps via `CoreEnvironment.apply` `[NetworkConfigWriter.java:write]` `[NetworkMonitorHolder.java:start]` `[RuntimeManager.java:applyEnvironment]` `[RuntimeManager.java:refreshNetwork]`.
- Creates onboarding/config/project/skill directories and atomically writes `jetski_state.pbtxt`, `antigravity_state.pbtxt`, `AGENTS.md`, `outside-of-project.json`, merged `mcp_config.json` files (with `android-device` and `chrome_devtools` bridge configs), and bundled skill files via temp-file + fsync + rename `[OnboardingSeeder.java:seed]` `[OnboardingSeeder.java:mergeBundledMcpServers]` `[OnboardingSeeder.java:writeIfParentReady]`.
- Creates `runtime/bin`, writes UTF-8 bridge/shim scripts and `.agy-bridges` with `0755` permissions (`Os.chmod`), and rewrites CRLF scripts in place; when executed, generated shims invoke `/system/bin/cmd camera set-torch-mode`, broadcast `com.agy.ACTION_TORCH` or `com.agy.ACTION_OPEN_URL` via `/system/bin/am broadcast`, emit stdout URL markers, run `pkg update && pkg install nodejs` under `.node-bootstrap.lock`, append `logs/node-bootstrap.log`, and post notifications to the local gateway or `agy-notify` `[ShellBridgeInstaller.java:writeScript]` `[ShellBridgeInstaller.java:writeTorchShims]` `[ShellBridgeInstaller.java:writeOpenUrlShim]` `[ShellBridgeInstaller.java:writeNodeBridge]` `[ShellBridgeInstaller.java:writeExecBridge]` `[ShellBridgeInstaller.java:normalizeRuntimeBinScripts]`.
- Mutates device flashlight hardware state via `CameraManager.setTorchMode` and logs diagnostic entries via `android.util.Log` `[TorchReceiver.java:setTorchMode]`.

# Logging & Telemetry (`com.agy.log`)

## Overview
Provides thread-safe in-memory FIFO ring buffers for command execution telemetry (`CommandHistory`, `CommandRecord`) and general runtime logs (`LogRingBuffer`, `LogRingBuffer.LogEntry`), stateless regex-based secret redaction (`LogRedactor`), and crash report assembly with UTF-8 JSON persistence (`CrashRecorder`).

## Interface
- `public final class CommandHistory` (`DEFAULT_CAPACITY = 100`) — synchronized bounded FIFO command history with constructors `CommandHistory()` and `CommandHistory(int capacity)` and methods `record(CommandRecord)`, `getRecent(int maxCount)`, `getById(String id)`, and static `toJsonArray(List<CommandRecord>)` `[CommandHistory.java:CommandHistory]` `[CommandHistory.java:DEFAULT_CAPACITY]` `[CommandHistory.java:record]` `[CommandHistory.java:getRecent]` `[CommandHistory.java:getById]` `[CommandHistory.java:toJsonArray]`
- `public final class CommandRecord` — immutable command telemetry record with constructor `CommandRecord(String id, long timestamp, String cmd, int exitCode, long durationMs, String stdout, String stderr, String status, String source)`, `public final` fields (`id`, `timestamp`, `cmd`, `exitCode`, `durationMs`, `stdout`, `stderr`, `status`, `source`), and `toJson()` emitting keys `id`, `time`, `cmd`, `exit_code`, `duration_ms`, `stdout`, `stderr`, `status`, `source` `[CommandRecord.java:CommandRecord]` `[CommandRecord.java:toJson]`
- `public final class CrashRecorder` — non-instantiable crash telemetry utility exposing `public static synchronized JSONObject recordCrash(Context, int exitCode, long uptimeMs, String errorDescription, LogRingBuffer)` (keys `timestamp`, `exit_code`, `uptime_ms`, `error`, `memory`, `storage`, optional `log_tail`) and `public static JSONObject getLatestCrash()` `[CrashRecorder.java:CrashRecorder]` `[CrashRecorder.java:recordCrash]` `[CrashRecorder.java:getLatestCrash]`
- `public final class LogRedactor` — non-instantiable secret redactor exposing `public static String redact(String line)` `[LogRedactor.java:LogRedactor]` `[LogRedactor.java:redact]`
- `public final class LogRingBuffer` (`DEFAULT_CAPACITY = 500`) — synchronized bounded FIFO log buffer with constructors `LogRingBuffer()` and `LogRingBuffer(int capacity)`, inner immutable `public static final class LogEntry` (`timestamp`, `channel`, `level`, `text`, `toJson()` emitting `time`, `channel`, `level`, `msg`), and methods `append(String, String, String)`, `appendLine(String)`, `getRecent(int)`, `getSince(long)`, and static `toJsonArray(List<LogEntry>)` `[LogRingBuffer.java:LogRingBuffer]` `[LogRingBuffer.java:DEFAULT_CAPACITY]` `[LogRingBuffer.java:LogEntry]` `[LogRingBuffer.java:LogEntry.toJson]` `[LogRingBuffer.java:append]` `[LogRingBuffer.java:appendLine]` `[LogRingBuffer.java:getRecent]` `[LogRingBuffer.java:getSince]` `[LogRingBuffer.java:toJsonArray]`

## Invariants
- `CommandHistory` enforces a minimum capacity of `10` (`Math.max(10, capacity)`), defaults to `DEFAULT_CAPACITY = 100`, ignores `null` records, evicts the oldest entry when full, synchronizes all instance operations, and returns defensive chronological copies from `getRecent` (clamping `maxCount` to `>= 1`) `[CommandHistory.java:DEFAULT_CAPACITY]` `[CommandHistory.java:CommandHistory(int)]` `[CommandHistory.java:record]` `[CommandHistory.java:getRecent]` `[CommandHistory.java:getById]`
- `CommandRecord` normalizes `null` `cmd`, `stdout`, `stderr` to `""`, `null` `status` to `"UNKNOWN"`, and `null` `source` to `"system"` (`id` may be `null`); `stdout` and `stderr` are redacted via `LogRedactor.redact` only during `toJson()`, while `cmd` is never redacted by `CommandRecord` `[CommandRecord.java:CommandRecord]` `[CommandRecord.java:toJson]`
- `LogRedactor.redact` is stateless and thread-safe, returns `null` and `""` unchanged, and applies case-insensitive `BEARER_PATTERN` (`Bearer [REDACTED]`), `CSRF_PATTERN` (`csrf_token=[REDACTED]`), and `KEY_PATTERN` (`$1=[REDACTED]` for `api_key`/`api-key`/`secret`/`password`) in order `[LogRedactor.java:BEARER_PATTERN]` `[LogRedactor.java:CSRF_PATTERN]` `[LogRedactor.java:KEY_PATTERN]` `[LogRedactor.java:redact]`
- `LogRingBuffer` enforces a minimum capacity of `50` (`Math.max(50, capacity)`), defaults to `DEFAULT_CAPACITY = 500`, synchronizes all instance methods, drops null/blank lines in `appendLine` while classifying levels with precedence `ERROR > WARN > DEBUG > INFO` under channel `"core"`, returns defensive copies from `getRecent` and `getSince` (strictly `entry.timestamp > sinceTimestamp`), and leaves `LogEntry.toJson()` unredacted `[LogRingBuffer.java:DEFAULT_CAPACITY]` `[LogRingBuffer.java:LogRingBuffer(int)]` `[LogRingBuffer.java:LogEntry]` `[LogRingBuffer.java:LogEntry.toJson]` `[LogRingBuffer.java:append]` `[LogRingBuffer.java:appendLine]` `[LogRingBuffer.java:getRecent]` `[LogRingBuffer.java:getSince]`
- `CrashRecorder.recordCrash` synchronizes on `CrashRecorder.class`, publishes via `volatile latestCrash` for lock-free `getLatestCrash()`, redacts `errorDescription` and up to 50 `log_tail` lines via `LogRedactor.redact` (omitting `log_tail` if `logBuffer == null`), reports memory and storage in integer MiB, persists UTF-8 JSON (2-space indent) strictly to `<filesDir>/logs/crashes/crash_<timestamp>.json`, and catches `Exception` without throwing `[CrashRecorder.java:recordCrash]` `[CrashRecorder.java:latestCrash]` `[CrashRecorder.java:getLatestCrash]` `[CrashRecorder.java:persistReport]`

## Side Effects
- Mutates bounded in-memory `LinkedList` state in `CommandHistory` and `LogRingBuffer` (reading `System.currentTimeMillis()` on `append`/`appendLine`) `[CommandHistory.java:record]` `[LogRingBuffer.java:append]` `[LogRingBuffer.java:appendLine]`
- Updates static `CrashRecorder.latestCrash`, queries JVM `Runtime` memory and `filesDir` usable/total disk space, creates `<filesDir>/logs/crashes` if absent, writes `crash_<timestamp>.json` to disk, and logs via `Log.i` / `Log.w` under tag `"CrashRecorder"` `[CrashRecorder.java:recordCrash]` `[CrashRecorder.java:persistReport]` `[CrashRecorder.java:TAG]`

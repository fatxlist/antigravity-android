# com.agy.install

## Overview
Installs, verifies, upgrades, and adapts the Bionic/Termux userspace prefix under `<filesDir>/usr`. Parses and validates the bundled `env/manifest.json`, extracts the bootstrap tarball (via system `toybox`/`tar` with a pure-Java ustar/GNU tar fallback), overlays bundled scripts/pkg/bus assets, rewrites hardcoded Termux prefixes, shebangs, and symlinks to the app's sandbox prefix, removes incompatible Termux startup hooks, validates the installed prefix with a `bash` smoke test and atomic rollback, and installs declared default seed packages with retry backoff and lock coordination.

## Interface
- `EnvInstaller` (`public final class` `[EnvInstaller.java:EnvInstaller]`):
  - `prefix(Context context)` — returns `<filesDir>/usr` via `EnvPaths.prefix` `[EnvInstaller.java:prefix]`.
  - `isInstalled(Context context)` — returns `true` iff `<prefix>/.installed` and `<prefix>/bin/bash` exist as files `[EnvInstaller.java:isInstalled]`.
  - `install(Context context)` (`synchronized`) — performs an atomic staged fresh install (returns `true`) or non-destructive managed-layer update on an existing prefix (returns `false`) `[EnvInstaller.java:install]`.
- `EnvBundleManifest` (`public final class` `[EnvBundleManifest.java:EnvBundleManifest]`):
  - Fields: `bundleId`, `bootstrapSha256`, `overlaySha256`, `pkgSha256`, `bootstrapSymlinkCount`, `seedPackages` `[EnvBundleManifest.java:bundleId]` `[EnvBundleManifest.java:bootstrapSha256]` `[EnvBundleManifest.java:overlaySha256]` `[EnvBundleManifest.java:pkgSha256]` `[EnvBundleManifest.java:bootstrapSymlinkCount]` `[EnvBundleManifest.java:seedPackages]`.
  - `load(AssetManager assets)` — parses and validates `assets/env/manifest.json` `[EnvBundleManifest.java:load]`.
  - `verifyBootstrap(File archive)` — checks `archive` SHA-256 against `bootstrapSha256` `[EnvBundleManifest.java:verifyBootstrap]`.
- `EnvPaths` (`public final class` `[EnvPaths.java:EnvPaths]`):
  - Layout & asset constants: `PREFIX_DIR` (`"usr"`), `MARKER` (`".installed"`), `BASH_REL` (`"bin/bash"`), `USER_DATA_DIR` (`".gemini"`), `ASSET_BOOTSTRAP`, `ASSET_BOOTSTRAP_PLAIN`, `ASSET_MANIFEST`, `ASSET_OVERLAY`, `ASSET_PKG`, `ASSET_BUS`, `FIX_PATHS_REL`, `SCRIPT_DIRS`, `TOYBOX`, `TAR`, `CHMOD` `[EnvPaths.java:PREFIX_DIR]` `[EnvPaths.java:MARKER]` `[EnvPaths.java:BASH_REL]` `[EnvPaths.java:USER_DATA_DIR]` `[EnvPaths.java:ASSET_BOOTSTRAP]` `[EnvPaths.java:ASSET_BOOTSTRAP_PLAIN]` `[EnvPaths.java:ASSET_MANIFEST]` `[EnvPaths.java:ASSET_OVERLAY]` `[EnvPaths.java:ASSET_PKG]` `[EnvPaths.java:ASSET_BUS]` `[EnvPaths.java:FIX_PATHS_REL]` `[EnvPaths.java:SCRIPT_DIRS]` `[EnvPaths.java:TOYBOX]` `[EnvPaths.java:TAR]` `[EnvPaths.java:CHMOD]`.
  - Prefix/shebang matching constants: `TERMUX_PREFIX`, `PREFIX_MARKER`, `TERMUX_SHEBANG`, `TERMUX_SHEBANG_LINES`, `ENV_SHEBANG`, `ENV_SHEBANG_LINES`, `TERMUX_ANY_PREFIX` `[EnvPaths.java:TERMUX_PREFIX]` `[EnvPaths.java:PREFIX_MARKER]` `[EnvPaths.java:TERMUX_SHEBANG]` `[EnvPaths.java:TERMUX_SHEBANG_LINES]` `[EnvPaths.java:ENV_SHEBANG]` `[EnvPaths.java:ENV_SHEBANG_LINES]` `[EnvPaths.java:TERMUX_ANY_PREFIX]`.
  - `prefix(Context context)` — resolves `new File(context.getFilesDir(), "usr")` `[EnvPaths.java:prefix]`.
- `BootstrapExtractor` (`public final class` `[BootstrapExtractor.java:BootstrapExtractor]`):
  - `extract(AssetManager assets, String asset, File prefix)` and `extract(AssetManager assets, String asset, File prefix, String expectedSha256, int expectedSymlinkCount)` — stages, optionally SHA-256-verifies, extracts, and validates the bootstrap archive `[BootstrapExtractor.java:extract]`.
- `OverlayCopier` (`public final class` `[OverlayCopier.java:OverlayCopier]`):
  - `overlay(AssetManager assets, String assetDir, File prefix)` — fail-closed copy requiring a non-empty asset directory `[OverlayCopier.java:overlay]`.
  - `copyTree(AssetManager assets, String assetDir, File dest)`, `copyFile(AssetManager assets, String asset, File dest)`, `list(AssetManager assets, String assetDir)` — asset copy/list helpers wrapping `IOException` into `IllegalStateException` `[OverlayCopier.java:copyTree]` `[OverlayCopier.java:copyFile]` `[OverlayCopier.java:list]`.
- `PkgInstaller` (`public final class` `[PkgInstaller.java:PkgInstaller]`):
  - `install(AssetManager assets, File prefix)` and `install(AssetManager assets, File root, String targetPrefix)` — copies `env/pkg` into `<root>/libexec/pkg` and generates the `<root>/bin/pkg` wrapper shim targeting `targetPrefix` `[PkgInstaller.java:install]`.
- `BusInstaller` (`public final class` `[BusInstaller.java:BusInstaller]`):
  - `install(AssetManager assets, File prefix)` — copies the optional `assets/bus` tree into `<prefix>/libexec/bus` and marks scripts executable `[BusInstaller.java:install]`.
- `SeedPackageInstaller` (`public final class` `[SeedPackageInstaller.java:SeedPackageInstaller]`):

  - `installDefaults(Context context, File prefix, List<String> packages)` — best-effort installation of missing default packages; returns `true` if any package was newly installed `[SeedPackageInstaller.java:installDefaults]`.
- `TarExtractor` (`public final class` `[TarExtractor.java:TarExtractor]`):
  - `untarGz(InputStream raw, File dest)` and `untar(InputStream in, File dest)` — pure-Java tar extractor handling regular files (`'0'`/`0`), directories (`'5'`), symlinks (`'2'`), GNU long name/link (`'L'`/`'K'`), and skipping PAX headers (`'x'`/`'g'`), returning the materialized symlink count `[TarExtractor.java:untarGz]` `[TarExtractor.java:untar]`.
- `TarHeader` (`public final class` `[TarHeader.java:TarHeader]`):
  - `readBlock(InputStream in, byte[] block)`, `isZeroBlock(byte[] block)`, `readField(byte[] block, int off, int len)`, `readOctal(byte[] block, int off, int len)` — 512-byte tar header parsing primitives `[TarHeader.java:readBlock]` `[TarHeader.java:isZeroBlock]` `[TarHeader.java:readField]` `[TarHeader.java:readOctal]`.
- `TarPath` (`public final class` `[TarPath.java:TarPath]`):
  - `normalize(String rawName)` — normalizes tar entry paths into safe relative `/`-separated paths (`""` for root/`.`, `null` for unsafe paths) `[TarPath.java:normalize]`.
- `TarRunner` (`public final class` `[TarRunner.java:TarRunner]`):
  - `runToyboxTar(File archive, File prefix, boolean gzip)` — extracts via `EnvPaths.TOYBOX` `tar`, falling back to `EnvPaths.TAR` `[TarRunner.java:runToyboxTar]`.
- `TermuxHooksRemover` (`public final class` `[TermuxHooksRemover.java:TermuxHooksRemover]`):
  - `remove(File prefix)` — deletes incompatible Termux startup hooks under `<prefix>/etc/profile.d` `[TermuxHooksRemover.java:remove]`.
- `TermuxPrefixRewriter` (`public final class` `[TermuxPrefixRewriter.java:TermuxPrefixRewriter]`):
  - `rewrite(File prefix)` and `rewrite(File root, String targetPrefix)` — rewrites `EnvPaths.TERMUX_ANY_PREFIX` occurrences to `targetPrefix` in text files under `EnvPaths.SCRIPT_DIRS` `[TermuxPrefixRewriter.java:rewrite]`.
- `TermuxShebangRewriter` (`public final class` `[TermuxShebangRewriter.java:TermuxShebangRewriter]`):
  - `rewrite(File prefix)` and `rewrite(File root, String targetPrefix)` — normalizes CRLF to LF and rewrites Termux/`/usr/bin/env` shebangs to `targetPrefix` across `EnvPaths.SCRIPT_DIRS` `[TermuxShebangRewriter.java:rewrite]`.
- `TermuxSymlinkFixer` (`public final class` `[TermuxSymlinkFixer.java:TermuxSymlinkFixer]`):
  - `fix(File prefix)` and `fix(File root, String targetPrefix)` — recursively repoints matching absolute Android-prefix symlinks to `targetPrefix`, returning the repointed count `[TermuxSymlinkFixer.java:fix]`.
- `TextFileDetector` (`public final class` `[TextFileDetector.java:TextFileDetector]`):
  - `isTextFile(byte[] data)` — returns `false` on ELF magic (`0x7f,'E','L','F'`) or any NUL byte, `true` otherwise `[TextFileDetector.java:isTextFile]`.
  - `isSymlink(File file)` — checks `OsConstants.S_ISLNK(Os.lstat(...).st_mode)` without following links, returning `false` on `ErrnoException` `[TextFileDetector.java:isSymlink]`.

## Invariants
- Manifest validation requires `schema == 1` (`SUPPORTED_SCHEMA`), four 64-character lowercase hex SHA-256 digests (`bundleId`, `bootstrapSha256`, `overlaySha256`, `pkgSha256`), `bootstrapSymlinkCount >= 1`, and `seedPackages` names matching `^[A-Za-z0-9][A-Za-z0-9+._-]*$` deduplicated into an unmodifiable list `[EnvBundleManifest.java:load]`.
- `EnvInstaller.install` rejects `null` `Context` with `IllegalArgumentException`, serializes concurrent callers via the static `synchronized` lock, requires `bootstrap.tar.gz` or `bootstrap.tar` to exist, and enforces that `prefix` lies strictly inside `context.getFilesDir()` without intersecting `<filesDir>/.gemini` (`EnvPaths.USER_DATA_DIR`) `[EnvInstaller.java:install]` `[EnvInstaller.java:validatePrefixLocation]`.
- Fresh installs stage into sibling `.usr-stage-<UUID>` in strict order (`BootstrapExtractor.extract` -> `OverlayCopier.overlay` -> `PkgInstaller.install` -> `prepareTree` -> `writeMarker` -> `validateTree`), require `bin/bash`, `bin/sh`, `bin/pkg`, `lib/libtermux-exec.so`, and minimum symlink counts, quarantine any incomplete prior prefix to `.usr-incomplete-<UUID>`, atomically rename into `prefix`, and run a 15-second `bash -c "exit 0"` smoke test with rollback to the quarantined prefix on failure `[EnvInstaller.java:installFresh]` `[EnvInstaller.java:validateTree]` `[EnvInstaller.java:bashSmokeTest]`.
- Existing installs are upgraded non-destructively: `updateManagedLayers` never wipes the prefix or overwrites the bootstrap when `bootstrap_sha256` differs or is `"legacy"` (recording `bootstrap_update_pending=true`), updates overlay/pkg only when their respective SHA-256 changed, and re-runs Termux fixers only if `prefixMoved || overlayChanged || pkgChanged || schema != "3"`; `writeMarker` verifies persisted `bundle_id` read-back `[EnvInstaller.java:updateManagedLayers]` `[EnvInstaller.java:writeMarker]`.
- `deleteTreeQuietly` never traverses symlink targets (unlinking the symlink itself) and refuses to delete paths equal to or outside `filesDir` `[EnvInstaller.java:deleteTreeQuietly]`.
- `BootstrapExtractor.extract` enforces SHA-256 equality when `expectedSha256 != null`, detects gzip strictly by magic bytes `0x1f 0x8b`, accepts `TarRunner.runToyboxTar` only when exit is 0, `<prefix>/bin` is a directory, `countSymlinks(prefix) >= expectedSymlinkCount`, and `verifyRequiredFiles` passes (requiring `bin/bash`, `bin/sh`, and symlinked `bin/sh` when `expectedSymlinkCount > 0`), otherwise falling back to `TarExtractor` and always deleting the temporary `bootstrap*.tar` file `[BootstrapExtractor.java:extract]` `[BootstrapExtractor.java:isGzip]` `[BootstrapExtractor.java:verifyRequiredFiles]`.
- `OverlayCopier.overlay` is fail-closed when `assets.list(assetDir)` is null or empty; `PkgInstaller.install` requires `env/pkg/pkg` to exist and emits `bin/pkg` referencing `targetPrefix` with `ShellQuote`-escaped paths; `BusInstaller.install` treats a missing or empty `assets/bus` tree as a no-op `[OverlayCopier.java:overlay]` `[PkgInstaller.java:install]` `[BusInstaller.java:install]`.
- `TarPath.normalize` rejects `null`, leading `/`, and any `..` segment; `TarExtractor` enforces `PathSafety.isInside(dest, parent)` for every entry, validates symlink targets before creation (no NUL/empty; absolute targets must match `EnvPaths.TERMUX_ANY_PREFIX` with no `..` suffix; relative targets must resolve inside `dest`), caps GNU `'L'`/`'K'` metadata reads at 8 MiB, rejects unsupported entry types, and skips 512-byte padding after every entry `[TarPath.java:normalize]` `[TarExtractor.java:untar]` `[TarExtractor.java:ensureParentInside]` `[TarExtractor.java:validateLinkTarget]` `[TarExtractor.java:readEntry]`.
- `TarHeader.readBlock` returns `false` only on EOF at offset 0 and throws `IOException` on partial blocks; `TarRunner.runToyboxTar` prefers `EnvPaths.TOYBOX` over `EnvPaths.TAR`, enforces a 120-second timeout, and succeeds only on exit code 0 `[TarHeader.java:readBlock]` `[TarRunner.java:runToyboxTar]` `[TarRunner.java:runTar]`.
- `TermuxHooksRemover` deletes only `01-termux-bootstrap-second-stage-fallback.sh` and `init-termux-properties.sh` under `<prefix>/etc/profile.d` after verifying `PathSafety.isInside(prefix, file)` `[TermuxHooksRemover.java:remove]`.
- `TermuxPrefixRewriter` and `TermuxShebangRewriter` traverse only `EnvPaths.SCRIPT_DIRS`, skip symlinks and binary files (`TextFileDetector.isTextFile`), preserve raw bytes via `ISO_8859_1`, and avoid rewriting unchanged files; `TermuxShebangRewriter` additionally bounds files to `2..2 MiB` (`MAX_NORMALIZE_BYTES`) and requires a newline within the first 256 bytes for `#!` files `[TermuxPrefixRewriter.java:rewriteIn]` `[TermuxPrefixRewriter.java:rewriteFile]` `[TermuxShebangRewriter.java:MAX_NORMALIZE_BYTES]` `[TermuxShebangRewriter.java:rewriteFile]`.
- `TermuxSymlinkFixer` never recurses into symlinked directories, repoints only symlinks matching `EnvPaths.TERMUX_ANY_PREFIX` whose remainder is empty or starts with `/`, and swaps atomically via sibling temp symlink plus `Os.rename` `[TermuxSymlinkFixer.java:fixIn]`.
- `SeedPackageInstaller.installDefaults` respects per-package retry backoff (6h `RETRY_BACKOFF_MS`; 15m `NODE_RETRY_BACKOFF_MS` for `nodejs`/`nodejs-lts`), skips when offline (`status=pending-network`), runs `pkg update` at most once per invocation (aborting on failure), checks availability via `<exec> --version` (10s timeout; `python`->`python3`, `nodejs`/`nodejs-lts`->`node`), enforces a 20-minute `pkg` timeout, truncates logs over 1 MiB, and serializes Node.js bootstrap with an atomic `<filesDir>/logs/.node-bootstrap.lock` directory lock (10-minute stale eviction) `[SeedPackageInstaller.java:installDefaults]` `[SeedPackageInstaller.java:isPackageAvailable]` `[SeedPackageInstaller.java:tryAcquireNodeBootstrapLock]` `[SeedPackageInstaller.java:runPkg]`.

## Side Effects
- Acquires the static `EnvInstaller.class` monitor lock, creates/stages `.usr-stage-<UUID>`, quarantines `.usr-incomplete-<UUID>` or `.usr-failed-<UUID>`, atomically renames into `<filesDir>/usr`, deletes failed staging trees, and atomically writes `<prefix>/.installed` via `AtomicFileWriter` `[EnvInstaller.java:install]` `[EnvInstaller.java:installFresh]` `[EnvInstaller.java:updateManagedLayers]`.
- Reads APK assets (`env/manifest.json`, bootstrap archive, `env/overlay`, `env/pkg`, optional `bus`), creates and deletes temporary `bootstrap*.tar` files, extracts files/directories/symlinks, sets POSIX modes (`FileModeUtil.applyMode`, `FileModeUtil.setExec`, recursive chmod), and writes `<root>/bin/pkg` `[EnvBundleManifest.java:load]` `[BootstrapExtractor.java:extract]` `[OverlayCopier.java:copyTree]` `[PkgInstaller.java:install]` `[BusInstaller.java:install]` `[TarExtractor.java:untar]`.
- Mutates files and symlinks in place under `<prefix>`: deletes profile hooks, atomically rewrites prefix strings (`AtomicFileWriter.writeBytes`), rewrites shebangs/CRLF (`FileOutputStream`), and atomically replaces symlinks (`Os.symlink` + `Os.rename` + `Os.remove`) `[TermuxHooksRemover.java:remove]` `[TermuxPrefixRewriter.java:rewriteFile]` `[TermuxShebangRewriter.java:rewriteFile]` `[TermuxSymlinkFixer.java:fixIn]`.
- Spawns external subprocesses: `toybox tar`/`/system/bin/tar` (120s timeout), `<prefix>/bin/bash -c "exit 0"` (15s timeout), `<prefix>/bin/<exec> --version` (10s timeout), and `<prefix>/bin/pkg update` / `pkg install <pkg>` (20m timeout, network downloads and prefix package mutations) `[TarRunner.java:runTar]` `[EnvInstaller.java:bashSmokeTest]` `[SeedPackageInstaller.java:isPackageAvailable]` `[SeedPackageInstaller.java:runPkg]`.
- Reads/writes `<filesDir>/.agy-env-seeds.properties`, appends/deletes `<filesDir>/env-seed-install.log` and `<filesDir>/logs/node-bootstrap.log`, creates/removes lock directory `<filesDir>/logs/.node-bootstrap.lock` with PID file, queries Android `ConnectivityManager`, and emits `android.util.Log` entries `[SeedPackageInstaller.java:installDefaults]` `[SeedPackageInstaller.java:tryAcquireNodeBootstrapLock]` `[SeedPackageInstaller.java:runPkg]` `[SeedPackageInstaller.java:hasNetwork]`.

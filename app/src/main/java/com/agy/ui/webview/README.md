# com.agy.ui.webview

## Overview

Encapsulates the host Android `WebView` stack that renders the Antigravity UI against the trusted local HTTPS core origin. Assembles the rich-image-capable `AgyWebView` (`WebViewHost`, `WebViewFactory`, `WebSettingsFactory`, `WebViewLifecycle`), injects boot configuration, CSP, and initial safe-area insets into `web/index.html` (`AppLoader`, `AppHtmlInjector`), enforces strict core-origin navigation, fail-closed TLS, audio-capture permission gating, and popup handling (`AgyWebViewClient`, `AgyWebChromeClient`, `PopupWindowHandler`), persists desktop-mode preferences (`DesktopModePrefs`), serves local static assets from `filesDir/web` (`LocalAssetServer`), and proxies embedded HTTP loopback plugin sidecars with per-port cookies and SSE streaming (`LoopbackSidecarProxy`).

## Interface

- `[WebViewHost.java:WebViewHost]` Primary host facade exposing `DESKTOP_UA`, `[WebViewHost.java:Listener]` (`onPageFinished(String)`, `onRenderProcessGone(boolean)`), overloaded constructors `(Context, ThemeManager, OAuthManager, AndroidBridge, [FileChooserCallback], [AudioPermissionCallback])`, `getWebView()`, `setListener(Listener)`, `loadApp()`, `loadApp(EdgeToEdge.InsetsRect, boolean)`, `isDesktopMode()`, `setDesktopMode(boolean)`, `freeMemory()`, `onRecordAudioPermissionResult(boolean)`, `cancelPendingPermissions()`, `hasPendingAudioPermissionRequest()`, and static `startUrl(int)` / `startUrl(int, String)`.
- `[AgyWebView.java:AgyWebView]` Custom `WebView` subclass overriding `onCreateInputConnection(EditorInfo)` and registering API 31+ `OnReceiveContentListener` for rich keyboard/clipboard image pasting.
- `[AgyWebChromeClient.java:AgyWebChromeClient]` `WebChromeClient` handling redacted JS console logging, popups, file chooser (`[AgyWebChromeClient.java:FileChooserCallback]`), and trusted-origin audio capture permission flow (`[AgyWebChromeClient.java:AudioPermissionCallback]`, `onPermissionRequest`, `onPermissionRequestCanceled`, `onRecordAudioPermissionResult`, `cancelPendingPermissions`, `hasPendingAudioPermissionRequest`).
- `[AgyWebViewClient.java:AgyWebViewClient]` `WebViewClient` enforcing trusted-core-origin top-level navigation and redirects, fail-closed SSL handling, OAuth interception, and request interception (`LocalAssetServer` -> `LoopbackSidecarProxy`).
- `[AppLoader.java:AppLoader]` Static loader `load(Context, WebView, ThemeManager, AndroidBridge)` and `load(Context, WebView, ThemeManager, AndroidBridge, EdgeToEdge.InsetsRect, boolean)`.
- `[AppHtmlInjector.java:AppHtmlInjector]` Static HTML injector `appendAssetVersion(String, String)` plus `inject(String, AndroidBridge, ThemeManager)`, `inject(String, AndroidBridge, ThemeManager, int, int, int, int, boolean)`, and `inject(String, AndroidBridge, ThemeManager, int, int, int, int, boolean, String)`.
- `[DesktopModePrefs.java:DesktopModePrefs]` Static preference accessors `isDesktopMode(Context)` and `setDesktopMode(Context, boolean)` in `"agy_prefs"`.
- `[LocalAssetServer.java:LocalAssetServer]` Stateful asset interceptor `intercept(Context, Uri, String, int)` caching `WebRoot` and serving `filesDir/web` files for the trusted core origin.
- `[LoopbackSidecarProxy.java:LoopbackSidecarProxy]` HTTP loopback sidecar proxy `intercept(WebResourceRequest, int)` with same-port redirect handling, per-port cookie jar, and SSE streaming.
- `[PopupWindowHandler.java:PopupWindowHandler]` External-browser popup router `handle(WebView, boolean, boolean, Message)`.
- `[WebSettingsFactory.java:WebSettingsFactory]` Static `WebSettings` configurator exposing `DESKTOP_UA`, `configure(WebView)`, and `applyDesktopMode(WebView, boolean)`.
- `[WebViewFactory.java:WebViewFactory]` Static `AgyWebView` factory `create(Context, AndroidBridge, ThemeManager)`.
- `[WebViewLifecycle.java:WebViewLifecycle]` Null-safe static lifecycle controls `resume(WebView)`, `pause(WebView)`, and `freeMemory(WebView)`.

## Invariants

- `[AgyWebViewClient.java:handleNavigation]` Permits only `null`, empty, `"about:blank"`, or `TrustedCoreOrigin.matches(uri, bridge.getEnginePort())` for top-level documents; non-core URLs always return `true` (blocked from rendering in-WebView) and open `http`/`https` externally except `googleapis.com/oauth2/v2/userinfo` and `googleapis.com/auth`; `[AgyWebViewClient.java:onPageStarted]` re-enforces this invariant on server-side redirects via `v.stopLoading()`.
- `[AgyWebViewClient.java:shouldOverrideUrlLoading]` For subframes (`!request.isForMainFrame()`), permits only `https`, `about`, or `http` on `[AgyWebViewClient.java:isLoopbackHost]` (`127.0.0.1` or case-insensitive `localhost` with `userInfo == null`); `[AgyWebViewClient.java:onReceivedSslError]` always fails closed via `handler.cancel()`.
- `[AgyWebViewClient.java:shouldInterceptRequest]` Tries `LocalAssetServer.intercept` before falling back to `LoopbackSidecarProxy.intercept`; deprecated `String` overload queries only `LocalAssetServer` as `GET`.
- `[AgyWebChromeClient.java:onPermissionRequest]` Denies any request unless `bridge != null`, `TrustedCoreOrigin.matches(request.getOrigin(), bridge.getEnginePort())`, and `PermissionRequest.RESOURCE_AUDIO_CAPTURE` is requested; grants strictly `RESOURCE_AUDIO_CAPTURE` and holds at most one `pendingAudioPermissionRequest` (denying superseded requests); `[AgyWebChromeClient.java:onConsoleMessage]` skips info/log messages in release builds and redacts warning/error messages/URLs via `SensitiveDataRedactor` before logging to `AGY_JS`; `[AgyWebViewClient.java:onRenderProcessGone]` forwards renderer exits to `Listener.onRenderProcessGone` and returns `true` so `MainActivity` can recreate the WebView.
- `[AgyWebView.java:IMAGE_MIME_TYPES]` Advertises `image/png`, `image/jpeg`, `image/webp`, `image/gif`, `image/*` via API 25+ `InputConnection` wrapping (`Api25InputConnectionHelper`, acquiring/releasing URI read grants in `finally`) and API 31+ `OnReceiveContentListener` (`Api31ReceiveContentHelper`, passing non-image items through unchanged).
- `[AppHtmlInjector.java:CSP]` Injects strict `<meta http-equiv="Content-Security-Policy">` (`object-src 'none'`, `base-uri 'self'`, loopback HTTP/WS allowed in `connect-src`/`frame-src`), JSON-quoted globals (`__APP_CONFIG__`, `__AG_ENDPOINTS__`, `__AG_CSRF__`, `__AG_HOST_THEME__`, `__AG_RESOLVED_THEME__`, `__AG_NATIVE_BRIDGE_TOKEN__`), `AndroidBridge = Android` alias, `window.dialog.showOpenDialog`, clamped non-negative initial safe-area insets (forcing `safeBottom = 0` when `extraKeysVisible`), and `[AppHtmlInjector.java:READY_SCRIPT]` (`./generated/patches/startup_ready.js`) after `<head>`, and rewrites local `./*.js`/`./*.css` `src`/`href` attributes via `appendAssetVersion(String, String)` when `assetVersion` is non-empty without altering URLs that already have query parameters or non-local schemes.
- `[AppLoader.java:load]` Reads `web/index.html` via `AssetReader.readString` (aborting if missing), applies `theme.applyToWebView` first, maps `initialInsets.navBottom` to `bottomDp` (or `0` when `extraKeysVisible`), passes `[AppLoader.java:resolveAssetVersion]` (`APP_VERSION_CODE + "_" + CORE_VERSION + "_" + lastUpdateTime`) to `AppHtmlInjector.inject`, and loads with base URL `"https://127.0.0.1:<port>/"` and history URL `origin + "?hostTheme=<mode>"`.
- `[LocalAssetServer.java:intercept]` Intercepts only `GET` requests on `TrustedCoreOrigin`, skips `"/"`, `/exa.`, `/jetski.`, `Service`, and `connect-websocket` paths, caches `WebRoot(filesDir, webDir, canonicalWeb)` in `volatile cachedWebRoot` once `webDir.isDirectory()` is true, enforces canonical containment inside `filesDir/web`, and serves only readable regular files as HTTP 200 (64 KiB `BufferedInputStream`) with `Access-Control-Allow-Origin: *` and `Cache-Control: public, max-age=31536000, immutable` when query `?v=` is non-empty (else `no-cache`).
- `[LoopbackSidecarProxy.java:isEligibleSidecarUri]` Proxies only `GET`/`HEAD` requests to `http://127.0.0.1:<port>` or `http://localhost:<port>` (`userInfo == null`, `port` in `1..65535`, `port != coreEnginePort`, excluding gateway ports `45160..45163`, `BuildConfig.GATEWAY_PORT`, and `SystemGatewayServer.getActivePort()` in `[LoopbackSidecarProxy.java:isExcludedGatewayPort]`).
- `[LoopbackSidecarProxy.java:MAX_REDIRECT_HOPS]` Follows up to 5 same-port loopback redirects (`301`/`302`/`303`/`307`/`308`), applies `[LoopbackSidecarProxy.java:CONNECT_TIMEOUT_MS]` (5s connect, 15s read or infinite `0` for `text/event-stream`), bounds per-port cookie storage to `MAX_TRACKED_PORTS = 64` and `MAX_COOKIES_PER_PORT = 32` (`[LoopbackSidecarProxy.java:storeSetCookie]`), strips hop-by-hop headers, and closes `HttpURLConnection` idempotently via `[LoopbackSidecarProxy.java:DisconnectingInputStream]`.
- `[WebSettingsFactory.java:configure]` Enables JS, DOM storage, zoom (without on-screen buttons), multi-window popups, SafeBrowsing (API 26+), and third-party cookies (API 21+), while disabling `allowFileAccess`, `allowFileAccessFromFileURLs`, and `allowUniversalAccessFromFileURLs`, and keeping `useWideViewPort` and `loadWithOverviewMode` enabled in both mobile and desktop modes so tablet viewport scaling works; `[WebViewFactory.java:create]` exposes `AndroidBridge` as `"Android"`, sets `RENDERER_PRIORITY_BOUND` (`waivedWhenNotVisible = true`) on API 26+, and enables WebContents debugging only in `BuildConfig.DEBUG` builds (API 19+).
- `[PopupWindowHandler.java:handle]` Always returns `true`, ignores empty/`about:blank` URLs, and routes every other popup URL to `OAuthManager.openInBrowser` while destroying the transient popup `WebView`; `[WebViewLifecycle.java:resume]` (`resume`, `pause`, `freeMemory`) are null-safe and catch exceptions.

## Side Effects

- `[WebViewFactory.java:create]` Allocates `AgyWebView`, paints its background, registers JS interface `"Android"`, attaches a focus touch listener, mutates `WebSettings` and `CookieManager` (`[WebSettingsFactory.java:configure]`), and enables global WebContents debugging in debug builds.
- `[WebViewHost.java:setDesktopMode]` Persists `"desktop_mode"` asynchronously to `"agy_prefs"` (`[DesktopModePrefs.java:setDesktopMode]`) and posts UA/viewport updates plus `webView.reload()` onto the WebView UI queue.
- `[AppLoader.java:load]` Reads APK asset `web/index.html`, mutates WebView background via `ThemeManager`, and invokes `webView.loadDataWithBaseURL`.
- `[AgyWebView.java:Api25InputConnectionHelper]` and `[AgyWebView.java:dispatchImagesAsync]` spawn background threads (`agy-ime-image`, `agy-receive-image`) to read image URIs via `ClipboardImageReader` and evaluate JS paste callbacks in the WebView.
- `[AgyWebChromeClient.java:onConsoleMessage]` Logs JS console messages to Logcat (`AGY_JS`); `[AgyWebChromeClient.java:onPermissionRequest]` grants/denies WebView `PermissionRequest`s and requests Android `RECORD_AUDIO` via callback.
- `[AgyWebViewClient.java:handleNavigation]` and `[PopupWindowHandler.java:handle]` open external browsers via `OAuthManager`, cancel TLS errors (`[AgyWebViewClient.java:onReceivedSslError]`), stop unauthorized redirects, and log redacted URLs (`WebViewHost`).
- `[LocalAssetServer.java:intercept]` Stats/canonicalizes paths and opens buffered `FileInputStream`s under `filesDir/web`.
- `[LoopbackSidecarProxy.java:intercept]` Opens synchronous loopback `HttpURLConnection` sockets, streams response bodies, mutates in-memory `cookiesByPort` (`[LoopbackSidecarProxy.java:captureSetCookies]`), queries `SystemGatewayServer.getActivePort()`, and logs warnings (`LoopbackSidecarProxy`).
- `[WebViewLifecycle.java:resume]` Calls `onResume()`/`resumeTimers()` and dispatches `CustomEvent('agy:host-resume')` in JS; `[WebViewLifecycle.java:pause]` calls `onPause()`/`pauseTimers()`; `[WebViewLifecycle.java:freeMemory]` invokes `webView.freeMemory()`; `[WebViewHost.java:WebViewHost]` wires `DownloadListener` to `FileDownloader.handleDownload`.

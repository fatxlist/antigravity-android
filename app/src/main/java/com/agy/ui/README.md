# com.agy.ui

## Overview

Hosts the primary Android UI entry points: `MainActivity` (the single-WebView host activity) and `ShareReceiverActivity` (the exported Android Share Sheet trampoline). `MainActivity` orchestrates `CoreServerService` startup and generation-tracked readiness observation, edge-to-edge/IME insets, live web surface colors, the `ExtraKeysBarView`, voice dictation and `VoiceForegroundService` state sync, loopback `LocalPreviewDialog`, Custom Tab remote portal navigation, SAF/file choosers, and runtime permissions across its six child UI packages (`download`, `extra`, `launcher`, `lifecycle`, `splash`, `webview`). `ShareReceiverActivity` extracts `ACTION_SEND`/`ACTION_SEND_MULTIPLE` payloads while temporary URI grants remain valid and forwards `EXTRA_SHARED_PAYLOAD_JSON` to the active host launcher activity.

## Interface

- `[MainActivity.java:MainActivity]` Primary host `Activity` implementing `WebViewHost.Listener`, `AgyWebChromeClient.FileChooserCallback`, and `AgyWebChromeClient.AudioPermissionCallback`.
- `[MainActivity.java:EXTRA_SHARED_PAYLOAD_JSON]` Intent extra key `"com.agy.EXTRA_SHARED_PAYLOAD_JSON"` carrying serialized Share Sheet payloads.
- `[MainActivity.java:REQUEST_POST_NOTIFICATIONS]` Runtime permission request code `1005`; `[MainActivity.java:REQUEST_DIR_CHOOSER]` SAF directory picker request code `2002`.
- `[MainActivity.java:activeActivity]` Public `volatile` static reference to the currently active `MainActivity` instance.
- `[MainActivity.java:onCreate]` Wires `ThemeManager`, `OAuthManager`, `RuntimeManager`, `ShizukuBridge`, `AndroidBridge`, `WebViewHost`, `ExtraKeysBarView`, `SplashController`, `VoiceDictationController`, `VoiceForegroundService.StateListener`, `PredictiveBackHelper`, insets/IME listeners, incoming share handling, storage permissions, and `CoreServerService` launch; lifecycle overrides `[MainActivity.java:onNewIntent]`, `[MainActivity.java:onConfigurationChanged]`, `[MainActivity.java:onResume]`, `[MainActivity.java:onPause]`, `[MainActivity.java:onStop]`, `[MainActivity.java:onDestroy]`, `[MainActivity.java:onTrimMemory]`, `[MainActivity.java:onWindowFocusChanged]`, `[MainActivity.java:onBackPressed]`, `[MainActivity.java:onActivityResult]`, and `[MainActivity.java:onRequestPermissionsResult]`.
- `[MainActivity.java:showFatalError]`, `[MainActivity.java:onPageFinished]`, `[MainActivity.java:dismissSplash]`, and `[MainActivity.java:onWebUiReady]` Splash, page-finish, and JS UI-ready coordination entry points.
- `[MainActivity.java:setExtraKeysVisible]`, `[MainActivity.java:openLocalPreview]`, `[MainActivity.java:openRemotePortal]`, `[MainActivity.java:isDesktopMode]`, `[MainActivity.java:setDesktopMode]`, `[MainActivity.java:applySurfaceColor]`, `[MainActivity.java:onShowFileChooser]`, and `[MainActivity.java:launchDirectoryPicker]` Native UI control and picker entry points.
- `[MainActivity.java:startVoiceDictation]`, `[MainActivity.java:stopVoiceDictation]`, `[MainActivity.java:isVoiceDictating]`, `[MainActivity.java:notifyVoiceServiceStateChanged]`, and `[MainActivity.java:requestRecordAudioPermission]` Voice dictation, voice service state, and audio permission controls.
- `[ShareReceiverActivity.java:ShareReceiverActivity]` Exported `final` Share Sheet trampoline `Activity` (`[ShareReceiverActivity.java:onCreate]`) forwarding extracted payloads to the resolved host activity.
- Subdirectories:
  - [download](./download/README.md) — `FileDownloader` WebView URL/blob/data-URL download routing, storage permission handshake (`REQUEST_STORAGE_DOWNLOAD`), and 64 MiB streaming Base64 staging.
  - [extra](./extra/README.md) — `ClipboardImageReader`, `ExtraKeysBarView`, `LocalPreviewDialog`, `SharePayloadExtractor`, and `VoiceDictationController` (`REQUEST_VOICE_DICTATION`, `REQUEST_RECORD_AUDIO_DICTATION`).
  - [launcher](./launcher/README.md) — `LauncherDarkActivity` and `LauncherLightActivity` concrete `MainActivity` subclasses for dark/light OS splash starting windows.
  - [lifecycle](./lifecycle/README.md) — `AppLifecycle`, `BackNavigator`, `PredictiveBackHelper`, and `ThemeRefresher` static lifecycle utilities.
  - [splash](./splash/README.md) — `SplashController`, `NativeSplashDotsView`, `SplashExitInstaller`, `SplashAnim31`, `SplashOverlayHtml`, `SplashRetryBridge`, `SplashRetryListener`, and `LogExporter`.
  - [webview](./webview/README.md) — `WebViewHost`, `AgyWebView`, `AgyWebChromeClient`, `AgyWebViewClient`, `AppLoader`, `AppHtmlInjector`, `DesktopModePrefs`, `LocalAssetServer`, `LoopbackSidecarProxy`, `PopupWindowHandler`, `WebSettingsFactory`, `WebViewFactory`, and `WebViewLifecycle`.

## Invariants

- `[MainActivity.java:coreStateListener]` Core readiness updates are event-driven via `CoreRuntimeState.addStateListener(coreStateListener)` in `onResume` (unregistered with pending `[MainActivity.java:coreWatchTask]`/`[MainActivity.java:splashDeadlineTask]` callbacks cancelled in `onPause`/`onDestroy`); `coreStateListener` posts `coreWatchTask` onto the main `Handler`, gated by `activityResumed`; `onPause()` skips `AppLifecycle.pause(...)` while `VoiceForegroundService.isActive()` or `webViewHost.hasPendingAudioPermissionRequest()` is true, and `onResume()` invokes `AppLifecycle.resume(...)` only when `webViewPaused` is true.
- `[MainActivity.java:watchCore]` `CoreRuntimeState.lastError` takes precedence over `serverUrl` (`restarting == true` shows transient splash error, `false` shows fatal error); WebView loading runs once per `CoreRuntimeState.readyGeneration` (re-showing splash on `generation > 1` and arming a 10000 ms `[MainActivity.java:splashWatchdog]`); if `serverUrl` stays null, arms single-shot `[MainActivity.java:splashDeadlineTask]` until `[MainActivity.java:SPLASH_TIMEOUT_MS]` (60000 ms) to display a fatal startup timeout without timer polling.
- `[MainActivity.java:onPageFinished]` Never dismisses the splash screen; dismissal occurs exclusively via `[MainActivity.java:dismissSplash]` (triggered by `AndroidBridge.onUiReady()` or `[MainActivity.java:splashWatchdog]`, which fires only when `appLoaded && !splash.isFatalShown()`).
- `[MainActivity.java:retryCore]` Resets `appLoaded`, `pageFinished`, `uiReady`, `loadedGeneration = -1`, and `splashDeadline`, stops `CoreServerService`, removes `RuntimePaths.RUNTIME_MARKER` if present, and restarts the service after 400 ms.
- `[MainActivity.java:onCreate]` Sets `setFitsSystemWindows(false)` on `rootLayout`, `contentColumn`, and `mainWebView`; uses `ImeInsetsAnimator` on API 30+ (deferring padding during `deferringIme` and toggling `window.__agSetImeAnimating`) and a 100 dp IME threshold below API 30, returning `EdgeToEdge.passSafeAreasConsumeIme(insets, extraVisible)`.
- `[MainActivity.java:pushSafeAreaInsetsToJs]` Pushes `--agy-inset-{top,bottom,left,right}` and `.agy-extra-keys` only when `uiReady || pageFinished`, deduplicated by inset/visibility key unless `force == true`; forces `bottomDp = 0` when `extraKeysBar` is `VISIBLE` while `extraKeysBar` absorbs `r.navBottom`; hiding via `[MainActivity.java:setExtraKeysVisible]` resets sticky modifiers and zeroes bar bottom inset.
- `[MainActivity.java:openLocalPreview]` Rejects any URL failing `LocalPreviewDialog.isAllowedLoopbackUrl(url)`; `[MainActivity.java:openRemotePortal]` rejects any URL not starting with `"https://antigravity.google.com"`.
- `[MainActivity.java:handleNotificationIntent]` Removes `HostActivityResolver.EXTRA_CASCADE_ID` immediately after extracting & sanitizing via `HostActivityResolver.sanitizeCascadeId`, queues `pendingCascadeId` until `uiReady` or `dismissSplash()`, and delivers via `[MainActivity.java:deliverOpenConversationToJs]` (escaping `U+2028`/`U+2029` and falling back to `window.__AG_PENDING_CASCADE_ID__`).
- `[MainActivity.java:handleSharedIntent]` Removes `EXTRA_SHARED_PAYLOAD_JSON` immediately upon ingestion to prevent duplicate replay and queues payloads in `pendingSharedPayloads` until `uiReady` or `dismissSplash()`; `[MainActivity.java:deliverSharedPayloadToJs]` escapes `U+2028`/`U+2029` after `JSONObject.quote` and falls back to `window.__AG_PENDING_SHARED_PAYLOAD__`.
- `[MainActivity.java:refreshTheme]` Clears `liveSurfaceColor` whenever its `ThemeColors.isDarkColor` polarity disagrees with `themeManager.isDark()` (and `onThemeApplied` always clears `liveSurfaceColor`).
- `[MainActivity.java:requestNotificationPermissionIfNeeded]` Requests `POST_NOTIFICATIONS` on API 33+ once `"asked_post_notifications"` in `"agy_prefs"` is unset and `awaitingStorageSettingsReturn` is false (so returning from storage Settings prompts for `POST_NOTIFICATIONS` even if All Files Access is declined).
- `[MainActivity.java:onShowFileChooser]` Completes any prior `filePathCallback` with `null` before assigning a new one, and resolves `null` on failure or in `onDestroy()`; `[MainActivity.java:onDestroy]` clears `VoiceForegroundService` listener, `activeActivity`, and `FileDownloader` pending task only when `activeActivity == this`.
- `[ShareReceiverActivity.java:onCreate]` Finishes immediately on non-share intents (`!SharePayloadExtractor.isShareIntent`), extracts stream URIs on background thread `"agy-share-extract"` before `finish()` so temporary `FLAG_GRANT_READ_URI_PERMISSION` grants stay valid, and `[ShareReceiverActivity.java:forwardAndFinish]` launches the `HostActivityResolver` class with `ACTION_MAIN` and `FLAG_ACTIVITY_NEW_TASK | FLAG_ACTIVITY_SINGLE_TOP | FLAG_ACTIVITY_CLEAR_TOP` (falling back to `MainActivity.class`).

## Side Effects

- `[MainActivity.java:startCoreService]` Starts `CoreServerService` via `CoreServiceLauncher.start(this)`; `[MainActivity.java:retryCore]` stops `CoreServerService`, deletes `<runtimeDir>/<RuntimePaths.RUNTIME_MARKER>`, and posts a delayed restart.
- `[MainActivity.java:onCreate]` Mutates `Window` flags/features, enables `EdgeToEdge`, sets static `activeActivity`, registers `VoiceForegroundService.StateListener` and `PredictiveBackHelper`, and wires `ExtraKeysBarView` hide actions to persist `ExtraKeysBarView.setVisiblePref(this, false)` and notify JS.
- `[MainActivity.java:requestStoragePermissions]`, `[MainActivity.java:requestNotificationPermissionIfNeeded]`, and `[MainActivity.java:requestRecordAudioPermission]` launch Android Settings or runtime permission dialogs (`REQUEST_STORAGE = 100`, `REQUEST_RECORD_AUDIO = 1003`, `REQUEST_POST_NOTIFICATIONS = 1005`) and persist `"asked_post_notifications" = true` in `"agy_prefs"`.
- `[MainActivity.java:openLocalPreview]`, `[MainActivity.java:openRemotePortal]`, `[MainActivity.java:onShowFileChooser]`, and `[MainActivity.java:launchDirectoryPicker]` present `LocalPreviewDialog`, launch Chrome Custom Tabs / external browsers, or launch file/SAF pickers; `[MainActivity.java:onActivityResult]` takes persistable `FLAG_GRANT_READ_URI_PERMISSION` on picked URIs and invokes `window.__onDirectoryPicked`.
- `[MainActivity.java:pushSafeAreaInsetsToJs]`, `[MainActivity.java:setWebImeAnimating]`, `[MainActivity.java:deliverOpenConversationToJs]`, `[MainActivity.java:deliverSharedPayloadToJs]`, `[MainActivity.java:dispatchExtraKeyToJs]`, `[MainActivity.java:notifyExtraKeysVisibilityChanged]`, `[MainActivity.java:deliverVoiceTextToJs]`, `[MainActivity.java:notifyVoiceDictationStateChanged]`, `[MainActivity.java:notifyVoiceServiceStateChanged]`, and `[MainActivity.java:refreshTheme]` evaluate JavaScript in the WebView to sync insets, IME animation, deep-linked conversation routes, shared payloads, extra keys, voice transcripts/state, and system theme changes.
- `[MainActivity.java:applySurfaceColor]` and `[MainActivity.java:setDesktopMode]` mutate Activity/WebView/ExtraKeysBarView appearance or persist desktop mode; `[MainActivity.java:refreshTheme]` and `[MainActivity.java:onStop]` schedule/apply `LauncherIconSwitcher` alias switches; `[MainActivity.java:onRequestPermissionsResult]` dispatches permission results to `WebViewHost`, `VoiceDictationController`, and `FileDownloader`.
- `[MainActivity.java:onDestroy]` Destroys `WebView`, `SplashController`, `VoiceDictationController`, and `LocalPreviewDialog`, unregisters `PredictiveBackHelper` and `VoiceForegroundService` listener, clears `FileDownloader` pending task, and detaches `AndroidBridge`.
- `[ShareReceiverActivity.java:onCreate]` Spawns `"agy-share-extract"` to copy shared streams into `cacheDir/shared/` via `SharePayloadExtractor.extractToJson`; `[ShareReceiverActivity.java:forwardAndFinish]` starts the host activity with `EXTRA_SHARED_PAYLOAD_JSON` and calls `finish()`.

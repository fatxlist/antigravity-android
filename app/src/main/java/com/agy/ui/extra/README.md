# com.agy.ui.extra

## Overview

Provides mobile host UX helpers and input/sharing adapters used by `MainActivity`: bounded clipboard/URI image extraction for WebView paste (`ClipboardImageReader`), a non-focusable terminal/chat extra-keys accessory bar (`ExtraKeysBarView`), an isolated loopback-only localhost preview dialog (`LocalPreviewDialog`), Android Share Sheet payload extraction into app cache (`SharePayloadExtractor`), and native `SpeechRecognizer` / `RecognizerIntent` voice dictation (`VoiceDictationController`).

## Interface

- `[ClipboardImageReader.java:ClipboardImageReader]` Static clipboard/URI image reader with `MAX_IMAGE_BYTES = 12 * 1024 * 1024`, value records `[ClipboardImageReader.java:ImageRef]` (`uri`, `mime`) and `[ClipboardImageReader.java:ImagePayload]` (`base64`, `mime`, `name`), and methods `hasClipboardImage(Context)`, `readClipboardImageJson(Context)`, `findPrimaryClipboardImage(Context)`, `detectImageMime(Context, Uri, ClipDescription)`, `isImageMime(String)`, `readImageFromUri(Context, Uri, String)`, and `deliverPastedImageToWebView(WebView, ImagePayload)`.
- `[ExtraKeysBarView.java:ExtraKeysBarView]` Custom `LinearLayout` accessory bar with `[ExtraKeysBarView.java:Listener]` (`onKeyPressed(String, boolean)`, `onHideRequested()`), instance methods `setListener(Listener)`, `setBottomInset(int)`, `applyTheme(boolean)`, `resetStickyModifiers()`, and preference helpers `isVisiblePref(Context)` / `setVisiblePref(Context, boolean)`.
- `[LocalPreviewDialog.java:LocalPreviewDialog]` Fullscreen `Dialog` hosting an isolated preview `WebView` via `LocalPreviewDialog(Activity, String, boolean)` and static validators `isAllowedLoopbackUrl(String)` and `isAllowedLoopbackUri(Uri)`.
- `[SharePayloadExtractor.java:SharePayloadExtractor]` Static Android Share Sheet extractor exposing `isShareIntent(Intent)`, `hasStreamUris(Intent)`, `extractToJson(Context, Intent)`, and `sanitizeFileName(String)`.
- `[VoiceDictationController.java:VoiceDictationController]` Main-thread voice dictation controller with request codes `REQUEST_VOICE_DICTATION = 2003` and `REQUEST_RECORD_AUDIO_DICTATION = 1004`, `[VoiceDictationController.java:Listener]` (`onVoiceText(String, boolean)`, `onDictationStateChanged(boolean, String)`), and methods `isListening()`, `start()`, `onRecordAudioPermissionResult(boolean)`, `stop()`, `handleActivityResult(int, int, Intent)`, and `destroy()`.

## Invariants

- `[ClipboardImageReader.java:MAX_IMAGE_BYTES]` Caps decoded/read image payloads at `12 * 1024 * 1024` bytes (12 MiB), rejecting 0-byte images, null streams, and non-`content`/`file` URI schemes; `[ClipboardImageReader.java:openSafeStream]` canonicalizes `file://` paths and refuses any file equal to or under `context.getApplicationInfo().dataDir`.
- `[ClipboardImageReader.java:findPrimaryClipboardImage]` Always inspects `ClipboardManager` on `Looper.getMainLooper()` (waiting up to 2 seconds via `CountDownLatch` from background threads, preferring `MainActivity.activeActivity` over application context); `[ClipboardImageReader.java:deliverPastedImageToWebView]` quotes `base64`, `mime`, and `name` with `JSONObject.quote`.
- `[ClipboardImageReader.java:detectImageMime]` Requires lowercase `"image/"` prefix after stripping `;` parameters, treats `"image/*"` as non-concrete (falling back to URI extension or `"image/png"`), and sanitizes filenames via `SharePayloadExtractor.sanitizeFileName`.
- `[ExtraKeysBarView.java:ExtraKeysBarView]` Explicitly disables focus (`setFocusable(false)`, `setFocusableInTouchMode(false)`) on all containers and key caps so taps never steal focus or dismiss the IME; exposes fixed keys (`ESC`, `TAB`, arrows, `/`, `@`, `|`, `~`), sticky `CTRL`, contextual shortcuts (`^C`, `^D`, `^Z`, `^L`), and hide (`✕`).
- `[ExtraKeysBarView.java:setCtrlActive]` Sticky `ctrlActive` defaults to `false`, toggles `ctrlShortcutsContainer` visibility, and auto-resets to `false` after any modified key press, shortcut tap, hide tap, or `resetStickyModifiers()`; `[ExtraKeysBarView.java:setBottomInset]` clamps `bottomPx >= 0`; `[ExtraKeysBarView.java:isVisiblePref]` defaults to `false` under `"agy_prefs"` key `"extra_keys_visible"`.
- `[LocalPreviewDialog.java:isAllowedLoopbackUri]` Strictly permits only `http`/`https` schemes with `userInfo == null` and host `"127.0.0.1"` or case-insensitive `"localhost"`.
- `[LocalPreviewDialog.java:LocalPreviewDialog]` Never calls `addJavascriptInterface` (zero native bridge exposure); `[LocalPreviewDialog.java:configureIsolatedSettings]` disables file/content/universal-file access and multi-window popups while enabling SafeBrowsing on API 26+; `[LocalPreviewDialog.java:LoopbackOnlyWebViewClient]` blocks non-loopback navigations (allowing `about:blank`), stops disallowed page loads, and unconditionally calls `handler.cancel()` on SSL errors.
- `[LocalPreviewDialog.java:destroyWebView]` Idempotently detaches and destroys the preview `WebView` guarded by `destroyed`.
- `[SharePayloadExtractor.java:isShareIntent]` Matches only `ACTION_SEND` and `ACTION_SEND_MULTIPLE`; `[SharePayloadExtractor.java:extractToJson]` returns `null` when text, subject, and files are all empty, emitting JSON `{"text", "subject", "files": [{"name", "path", "mime"}]}`.
- `[SharePayloadExtractor.java:copyContentUri]` Accepts strictly `content://` URIs (rejecting `file://` and others), caps extraction at `[SharePayloadExtractor.java:MAX_FILES]` (`20`) files and `[SharePayloadExtractor.java:MAX_FILE_BYTES]` (`50 MiB`) per file, prunes regular files older than `[SharePayloadExtractor.java:STALE_AGE_MS]` (24 hours) in `cacheDir/shared/`, and enforces canonical containment inside `cacheDir/shared/` via `[SharePayloadExtractor.java:getSafeUniqueFile]` (`PathSafety.isInside`).
- `[SharePayloadExtractor.java:sanitizeFileName]` Strips directory paths, caps length to 120 chars, replaces control and reserved path characters with `_`, strips leading `.`, and maps empty/`.`/`..` to `""`.
- `[VoiceDictationController.java:VoiceDictationController]` Must be driven on the main thread; `[VoiceDictationController.java:start]` rejects null/finishing/destroyed activities and gates on `Manifest.permission.RECORD_AUDIO` on API 23+ via `pendingStartAfterPermission`; `[VoiceDictationController.java:onRecordAudioPermissionResult]` no-ops unless `pendingStartAfterPermission` is set.
- `[VoiceDictationController.java:startInternal]` Stops any prior session, resets `readyForSpeech`/`fallbackAttemptedForSession`, prefers `SpeechRecognizer` when `SpeechRecognizer.isRecognitionAvailable` is true, destroys the recognizer via `destroyRecognizerQuietly()` on `ERROR_CLIENT`/`ERROR_RECOGNIZER_BUSY`/`ERROR_AUDIO`/`ERROR_SERVER`, and falls back once to `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` (`REQUEST_VOICE_DICTATION`) on pre-ready service failures (`ERROR_CLIENT`, `ERROR_SERVER`, `ERROR_RECOGNIZER_BUSY`, or `ERROR_INSUFFICIENT_PERMISSIONS` when `RECORD_AUDIO` is granted) or launch failure; `[VoiceDictationController.java:firstNonEmpty]` suppresses blank transcripts; `[VoiceDictationController.java:mapError]` maps error codes to fixed strings (`audio`, `client`, `permission_denied`, `network`, `no_match`, `busy`, `server`, `speech_timeout`, `unavailable`, `cancelled`, or `error_<code>`).

## Side Effects

- `[ClipboardImageReader.java:findPrimaryClipboardImageOnMain]` Reads `ClipboardManager` primary clip; `[ClipboardImageReader.java:openSafeStream]` and `[ClipboardImageReader.java:resolveFileName]` perform `ContentResolver` IPC queries/reads or `FileInputStream` disk reads; `[ClipboardImageReader.java:deliverPastedImageToWebView]` evaluates `window.__agDeliverPastedImage(...)` in `WebView`; `[ClipboardImageReader.java:readClipboardImageJson]` logs warnings to Logcat.
- `[ExtraKeysBarView.java:setVisiblePref]` Writes `"extra_keys_visible"` asynchronously to SharedPreferences `"agy_prefs"`; `[ExtraKeysBarView.java:hapticTap]` triggers `HapticFeedbackConstants.KEYBOARD_TAP`; button taps invoke `Listener` callbacks and mutate view styling/padding/visibility.
- `[LocalPreviewDialog.java:LocalPreviewDialog]` Configures dialog window via `EdgeToEdge.enable`, instantiates and destroys a `WebView`, performs loopback HTTP/HTTPS loads, mutates toolbar/progress views, and logs blocked URLs (redacted via `SensitiveDataRedactor.safeUrl`) to Logcat (`[LocalPreviewDialog.java:LoopbackOnlyWebViewClient]`).
- `[SharePayloadExtractor.java:extractToJson]` Creates `cacheDir/shared/`, deletes files older than 24h (`[SharePayloadExtractor.java:pruneStaleFiles]`), reads external `ContentResolver` streams, writes copied files to cache (deleting partials on overflow/error in `[SharePayloadExtractor.java:copyContentUri]`), and logs warnings/errors to Logcat.
- `[VoiceDictationController.java:start]` Requests `RECORD_AUDIO` runtime permission (API 23+); `[VoiceDictationController.java:ensureRecognizer]` binds `SpeechRecognizer` and starts microphone capture (`[VoiceDictationController.java:startInternal]`); `[VoiceDictationController.java:startIntentFallback]` launches an external speech activity via `startActivityForResult`; `[VoiceDictationController.java:stop]` and `[VoiceDictationController.java:destroy]` cancel/destroy the recognizer and notify `Listener`.

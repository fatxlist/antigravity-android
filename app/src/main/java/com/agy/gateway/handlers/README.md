# System Gateway Handlers (`com.agy.gateway.handlers`)

## Overview
Implements the eight domain handler classes invoked by `GatewayDispatcher` to execute Android host actions over the loopback `SystemGatewayServer`. Each handler accepts a JSON payload and returns a `JSONObject` with an `ok` boolean status covering external browser opening, clipboard I/O, device telemetry/haptics/toasts/torch, runtime diagnostics/repair, sync/async shell and Shizuku command execution, multi-channel notifications with approvals and subagent progress, wake locks, and sandboxed offscreen WebView automation.

## Interface
- `public final class BrowserHandler` (`BrowserHandler(Context)`) — `handle(JSONObject)` opens required trimmed `url` via `UriDispatcher.open` and returns `{ok, url}` `[BrowserHandler.java:BrowserHandler]` `[BrowserHandler.java:handle]`
- `public final class ClipboardHandler` (`ClipboardHandler(Context)`) — `handle(JSONObject)` reads (`action="get"`, returning `{ok, text}`) or writes (default `"set"`, `text`, returning `{ok, length}`) the primary clipboard on the main looper `[ClipboardHandler.java:ClipboardHandler]` `[ClipboardHandler.java:handle]`
- `public final class DeviceHandler` (`DeviceHandler(Context)`) — `handleSystemInfo()` (`battery`, `charging`, `network`, `storage_free_mb`, `memory_free_mb`), `handleVibrate(JSONObject)` (`duration_ms`, default `100`), `handleToast(JSONObject)` (`message`, `duration` `"long"`/short), and `handleTorch(JSONObject)` (`enabled`, optional `state` `"on"`/`"1"`/`"true"`/`"off"`/`"0"`/`"false"`) `[DeviceHandler.java:DeviceHandler]` `[DeviceHandler.java:handleSystemInfo]` `[DeviceHandler.java:handleVibrate]` `[DeviceHandler.java:handleToast]` `[DeviceHandler.java:handleTorch]`
- `public final class DoctorHandler` (`DoctorHandler(Context)`) — `doctor()` runs 10 checks (`core_ready`, `usr_env`, `runtime`, `web`, `gateway`, `storage`, `logs_dir`, `daemon`, `notification_permission`, `microphone_permission`) returning `{ok, summary, checks, app_version}`; `repair(JSONObject)` runs `ensure_logs_dir` and `cleanup_cache_tmp`; `public static long readLiveDaemonPid(File, File)` validates live `agy-daemon` PIDs against `/proc/<pid>/cmdline` `[DoctorHandler.java:DoctorHandler]` `[DoctorHandler.java:doctor]` `[DoctorHandler.java:repair]` `[DoctorHandler.java:readLiveDaemonPid]`
- `public final class ExecHandler` (`ExecHandler(Context, CommandHistory, LogRingBuffer)`) — handles `exec`, `exec_start`, `exec_status`, `exec_cancel`, `exec_list` via `handle(JSONObject)` (sync or delegates to `start` when `async=true`), `start(JSONObject)` (`cmd`, `source`, `timeout_ms` default `30000`, `rish`, `cwd`), `status(JSONObject)` (`id`, `stdout_offset`, `stderr_offset`, `include_output`), `cancel(JSONObject)` (`id`), and `list(JSONObject)` (`active_only`, `limit`) `[ExecHandler.java:ExecHandler]` `[ExecHandler.java:handle]` `[ExecHandler.java:start]` `[ExecHandler.java:status]` `[ExecHandler.java:cancel]` `[ExecHandler.java:list]`
- `public final class NotificationHandler` (`NotificationHandler(Context)`) — public channels `CHANNEL_TASKS = "agy_tasks"`, `CHANNEL_ALERTS = "agy_alerts"`, `CHANNEL_SUBAGENTS = "agy_subagents"`; `handle(JSONObject)` posts/cancels notifications, progress bars, optional `cascade_id` deep-link intents, and tool-approval `RemoteInput` actions (routing `type="subagent"` to `handleSubagent`); `handleSubagent(JSONObject)` manages subagent progress and cancel actions (`"post"`, `"cancel"`, `"dismiss"`, `"done"`) `[NotificationHandler.java:NotificationHandler]` `[NotificationHandler.java:CHANNEL_TASKS]` `[NotificationHandler.java:CHANNEL_ALERTS]` `[NotificationHandler.java:CHANNEL_SUBAGENTS]` `[NotificationHandler.java:handle]` `[NotificationHandler.java:handleSubagent]`
- `public final class PowerHandler` (`PowerHandler(Context)`) — `handle(JSONObject)` manages tagged `PARTIAL_WAKE_LOCK`s (`action`: `"release"`, `"status"`, or default `"acquire"`, `tag` default `"agy_task"`, `timeout_ms` default `0`); `releaseAll()` releases and clears all held wake locks `[PowerHandler.java:PowerHandler]` `[PowerHandler.java:handle]` `[PowerHandler.java:releaseAll]`
- `public final class WebBrowserAutomationHandler` (`WebBrowserAutomationHandler(Context)`) — handles gateway command `browser_auto` via `handle(JSONObject)` with 8 actions (`navigate`, `eval`, `click`, `type`, `get_text`, `screenshot`, `console_logs`, `close`), lifecycle cleanup `close()`, and package-private `isAllowedUrl(String)` `[WebBrowserAutomationHandler.java:WebBrowserAutomationHandler]` `[WebBrowserAutomationHandler.java:handle]` `[WebBrowserAutomationHandler.java:close]` `[WebBrowserAutomationHandler.java:isAllowedUrl]`

## Invariants
- `BrowserHandler` rejects empty/whitespace-only `url` before dispatch; `ClipboardHandler` executes all `ClipboardManager` access on `Looper.getMainLooper()`, blocking up to `1500` ms on `"get"` (returning `""` on empty/timeout/error) while `"set"` posts asynchronously with label `"antigravity"` `[BrowserHandler.java:handle]` `[ClipboardHandler.java:handle]`
- `DeviceHandler.handleSystemInfo` reports usable `filesDir` storage and JVM heap headroom in MiB and sets `charging=true` iff battery status is `BATTERY_STATUS_CHARGING` or `BATTERY_STATUS_FULL`; `handleVibrate` uses `VibrationEffect.createOneShot` on API 26+ and rejects missing vibrators; `handleTorch` lets `state` override `enabled` `[DeviceHandler.java:handleSystemInfo]` `[DeviceHandler.java:handleVibrate]` `[DeviceHandler.java:handleTorch]`
- `DoctorHandler.doctor` flags storage `<200` MB as `"error"` and `<1024` MB as `"warn"`, `runtime` or `web/index.html` absence as `"error"`, and checks `daemon` (`readLiveDaemonPid` against `<filesDir>/.gemini/antigravity-app/daemon/daemon.pid` and `/proc/<pid>/cmdline`), `notification_permission`, and `microphone_permission` as `"warn"` when inactive/missing; `repair` deletes only non-recursive top-level regular files in `cacheDir` matching `*.tmp` or `tmp*` `[DoctorHandler.java:doctor]` `[DoctorHandler.java:repair]` `[DoctorHandler.java:readLiveDaemonPid]`
- `ExecHandler` generates IDs `"cmd_<epochMs>_<4-char-uuid>"`, executes `rish` (probing `usr/bin/rish`, `runtime/bin/rish`, `bin/rish`) or `/system/bin/sh -c` with `LD_LIBRARY_PATH` removed, `HOME=filesDir`, `RISH_APPLICATION_ID=packageName`, and closed stdin; caps stdout and stderr independently at `MAX_OUTPUT_CHARS = 262144` chars (`\n[output truncated]`), evicts terminal tasks older than `TASK_RETENTION_MS = 600000` ms (or `>60000` ms when exceeding `MAX_RETAINED_TASKS = 128`), and clamps `list` `limit` to `[1, 100]` `[ExecHandler.java:ExecTask]` `[ExecHandler.java:ExecTask.runBlocking]` `[ExecHandler.java:ExecTask.drainStream]` `[ExecHandler.java:cleanupTasks]` `[ExecHandler.java:list]`
- `NotificationHandler` configures channel importances (`agy_tasks=DEFAULT`, `agy_alerts=HIGH`, `agy_subagents=LOW` without badges), validates requested channels against those three known IDs (falling back to `defaultChannel`), derives a deterministic default ID from `tag` (`1000 + Math.abs(tag.hashCode() % 89000)`) when `id` is omitted, honors `only_alert_once`, caps attached actions at 3, activates 3-action tool-approval preset (`approve`, `deny`, `deny_with_comment` with `RemoteInput` key `KEY_APPROVAL_COMMENT` and `FLAG_MUTABLE` on API 31+) on `approval=true` or `type="tool_approval"`, enables `BigTextStyle` when `message.length() > 40`, and assigns deterministic subagent tags (max 48 sanitized chars) and notification IDs (`5100..6099`) `[NotificationHandler.java:initChannels]` `[NotificationHandler.java:isKnownChannel]` `[NotificationHandler.java:postOrCancel]` `[NotificationHandler.java:handleSubagent]`
- `PowerHandler` prunes unheld locks in `ConcurrentHashMap` before every action, exclusively creates `PARTIAL_WAKE_LOCK`s prefixed `"com.agy:wakelock:" + tag`, and makes `"acquire"` idempotent while a tag is already held `[PowerHandler.java:locks]` `[PowerHandler.java:cleanupUnheld]` `[PowerHandler.java:handle]`
- `WebBrowserAutomationHandler` serializes all `handle()` and `close()` operations under `opLock`, performs all `WebView` work on `Looper.getMainLooper()` with bounded `CountDownLatch` waits, registers zero `@JavascriptInterface` bridges, forces `View.LAYER_TYPE_SOFTWARE`, disables file/content/universal file URL access, geolocation, form save, multi-window, and Web SQL (`setAllowFileAccess(false)`, `setAllowContentAccess(false)`, `setAllowFileAccessFromFileURLs(false)`, `setAllowUniversalAccessFromFileURLs(false)`, `setGeolocationEnabled(false)`, `setDatabaseEnabled(false)`, `setSupportMultipleWindows(false)`), and enforces an `http`/`https` allowlist with non-empty host on both initial `navigate` and redirects `[WebBrowserAutomationHandler.java:opLock]` `[WebBrowserAutomationHandler.java:ensureWebView]` `[WebBrowserAutomationHandler.java:isAllowedUrl]` `[WebBrowserAutomationHandler.java:createWebViewClient]`
- `WebBrowserAutomationHandler` clamps viewports to `[320..2160] x [320..3840]`, `navigate` timeout to `[1000..25000]` ms, `eval` timeout to `[500..25000]` ms, `get_text` `max_chars` to `[100..200000]`, bounds `consoleBuffer` at `MAX_CONSOLE_LOGS = 200` (FIFO eviction), escapes injected JS strings via `JSONObject.quote`, confines screenshot paths via `PathSafety.isInside` to `cacheDir`, `filesDir`, `externalCacheDir`, `externalFilesDir(null)`, or `Environment.getExternalStorageDirectory()`, and always recycles screenshot `Bitmap`s in `finally` `[WebBrowserAutomationHandler.java:MIN_DIM]` `[WebBrowserAutomationHandler.java:MAX_TIMEOUT_MS]` `[WebBrowserAutomationHandler.java:MAX_CONSOLE_LOGS]` `[WebBrowserAutomationHandler.java:resolveScreenshotFile]` `[WebBrowserAutomationHandler.java:handleScreenshot]`

## Side Effects
- Opens external URLs/Custom Tabs via `UriDispatcher.open`, reads/writes the system clipboard, queries battery/network/storage/JVM metrics, triggers vibration, displays Toasts, and toggles flashlight hardware via `TorchReceiver.setTorchMode` `[BrowserHandler.java:handle]` `[ClipboardHandler.java:handle]` `[DeviceHandler.java:handleSystemInfo]` `[DeviceHandler.java:handleVibrate]` `[DeviceHandler.java:handleToast]` `[DeviceHandler.java:handleTorch]`
- Creates `<filesDir>/logs` and deletes temporary cache files (`*.tmp`, `tmp*`) in `cacheDir` `[DoctorHandler.java:doctor]` `[DoctorHandler.java:repair]`
- Spawns daemon threads (`ExecTask-*`, `StdoutDrain-*`, `StderrDrain-*`) and OS child processes (`/system/bin/sh` or `rish`), forcibly kills timed-out/cancelled subprocesses, records `CommandRecord`s in `CommandHistory`, and emits debug logs to `LogRingBuffer` `[ExecHandler.java:start]` `[ExecHandler.java:ExecTask.runBlocking]` `[ExecHandler.java:ExecTask.recordResult]`
- Creates Android `NotificationChannel`s, posts/cancels status bar notifications, registers pending records in `ApprovalActionReceiver`, and acquires/releases Android `PARTIAL_WAKE_LOCK`s `[NotificationHandler.java:initChannels]` `[NotificationHandler.java:postOrCancel]` `[PowerHandler.java:handle]` `[PowerHandler.java:releaseAll]`
- Instantiates/destroys an offscreen `WebView`, performs network navigation and page DOM/JS execution, allocates/recycles offscreen `ARGB_8888` `Bitmap`s, and writes PNG screenshots to allowed app/external storage paths `[WebBrowserAutomationHandler.java:ensureWebView]` `[WebBrowserAutomationHandler.java:handleNavigate]` `[WebBrowserAutomationHandler.java:handleClick]` `[WebBrowserAutomationHandler.java:handleType]` `[WebBrowserAutomationHandler.java:handleScreenshot]` `[WebBrowserAutomationHandler.java:destroyWebViewOnMainThread]`

# System Gateway (`com.agy.gateway`)

## Overview
Provides the loopback-only HTTP server (`SystemGatewayServer`) and JSON command router (`GatewayDispatcher`) that bridge the Linux userspace and AI agent layer to Android host services and domain handlers. Incoming authenticated requests are either served directly by HTTP status/telemetry endpoints or dispatched as structured JSON commands to [`./handlers/README.md`](./handlers/README.md) and core runtime components.

## Interface
- `public final class SystemGatewayServer` — loopback HTTP server with constants `DEFAULT_PORT = 45160`, `TOKEN_HEADER = "x-agy-gateway-token"`, and `AUTH_HEADER = "authorization"`, constructors `SystemGatewayServer(Context, LogRingBuffer)` and `SystemGatewayServer(Context, LogRingBuffer, int port)`, lifecycle methods `start()` / `stop()`, port getters `getPort()` / `getActivePort()`, and static auth helpers `extractTokenFromHeaders(Map<String, String>)` / `isAuthorized(String, Map<String, String>)` `[SystemGatewayServer.java:DEFAULT_PORT]` `[SystemGatewayServer.java:TOKEN_HEADER]` `[SystemGatewayServer.java:AUTH_HEADER]` `[SystemGatewayServer.java:SystemGatewayServer]` `[SystemGatewayServer.java:getPort]` `[SystemGatewayServer.java:getActivePort]` `[SystemGatewayServer.java:start]` `[SystemGatewayServer.java:stop]` `[SystemGatewayServer.java:extractTokenFromHeaders]` `[SystemGatewayServer.java:isAuthorized]`
- Authenticated HTTP routes served by `SystemGatewayServer`: `GET /gateway/status*` and `GET /gateway/health*` (runtime/core/env/memory status JSON), `GET /gateway/logs*` (last 50 `LogRingBuffer` entries), `GET /gateway/commands*` (last 20 `CommandHistory` entries), `GET /gateway/crash*` (`CrashRecorder.getLatestCrash()`), `GET /gateway/approval*` (`id`, `wait_ms` -> `ApprovalActionReceiver.poll`), `GET /gateway/voice/status*` (`VoiceForegroundService.getStatusJson()`), `POST /gateway` (or `/gateway?...`, JSON `{command, payload}` -> `GatewayDispatcher.dispatch`), and compatibility alias `POST /gateway/notify` (unwrapping `payload` if present, dispatching `"notify"`) `[SystemGatewayServer.java:handleClient]`
- `public final class GatewayDispatcher` with `GatewayDispatcher(Context, LogRingBuffer)`, `getCommandHistory()`, `releaseResources()`, and `dispatch(String command, JSONObject payload)` routing commands: `notify`, `subagent_notify`, `approval_poll`, `voice_service`, `open_url`, `browser_auto`, `wakelock`, `clipboard` / `clipboard_set`, `system_info`, `vibrate`, `toast`, `torch`, `logs`, `exec`, `exec_start`, `exec_status` / `exec_poll`, `exec_cancel`, `exec_list` / `tasks`, `commands`, `command_get`, `crash`, `status` / `health`, `doctor`, and `repair` (unknown commands return `{ok: false, error: "unknown command: <command>"}`) `[GatewayDispatcher.java:GatewayDispatcher]` `[GatewayDispatcher.java:getCommandHistory]` `[GatewayDispatcher.java:releaseResources]` `[GatewayDispatcher.java:dispatch]`
- Child package: [handlers](./handlers/README.md) — implements the eight Android domain handlers (`BrowserHandler`, `ClipboardHandler`, `DeviceHandler`, `DoctorHandler`, `ExecHandler`, `NotificationHandler`, `PowerHandler`, `WebBrowserAutomationHandler`) invoked by `GatewayDispatcher`.

## Invariants
- `SystemGatewayServer` binds exclusively to loopback `127.0.0.1` (`InetAddress.getByName("127.0.0.1")`) with `setReuseAddress(true)` and backlog `50`, defaulting to `DEFAULT_PORT = 45160`; if the initial bind throws `IOException`, it probes once at `port + 2` on `127.0.0.1` and exits the accept thread without further probing if that fails `[SystemGatewayServer.java:DEFAULT_PORT]` `[SystemGatewayServer.java:start]`
- Shared-secret authentication reads `<filesDir>/logs/gateway.token` (up to 256 UTF-8 bytes trimmed, requiring length `>= 32`) or generates a 32-byte `SecureRandom` 64-char lowercase hex token, enforcing owner-only `0600` permissions (`Os.chmod` + Java `File` flags) `[SystemGatewayServer.java:loadOrCreateToken]` `[SystemGatewayServer.java:enforcePrivatePermissions]`
- Every request with path starting with `"/gateway"` requires `isAuthorized(gatewayToken, headers)` using constant-time `MessageDigest.isEqual` on UTF-8 bytes (`X-Agy-Gateway-Token` takes precedence over `Authorization: Bearer <token>`); unauthorized calls receive HTTP `401 Unauthorized` with `{ok: false, error: "unauthorized"}`, and unmatched routes return HTTP `404 Not Found` with `{ok: false, error: "not found"}` `[SystemGatewayServer.java:handleClient]` `[SystemGatewayServer.java:extractTokenFromHeaders]` `[SystemGatewayServer.java:isAuthorized]`
- Client sockets enforce `CLIENT_SOCKET_TIMEOUT_MS = 30_000` ms (`SO_TIMEOUT`), header lines are capped at `MAX_HEADER_LINE_BYTES = 8192` bytes, `Content-Length` must lie in `[0, 4 * 1024 * 1024]` (4 MiB) with exact-length body reads (premature EOF throws `IOException`), and all responses emit `Content-Type: application/json; charset=utf-8`, `Content-Length`, and `Connection: close` `[SystemGatewayServer.java:CLIENT_SOCKET_TIMEOUT_MS]` `[SystemGatewayServer.java:MAX_HEADER_LINE_BYTES]` `[SystemGatewayServer.java:handleClient]` `[SystemGatewayServer.java:readBody]`
- Request handling is bounded to a fixed 8-thread worker pool (`Executors.newFixedThreadPool(8)`) plus 1 daemon accept thread `"AgyGatewayServer"`; `start()` is a no-op if already running, and `stop()` calls `executor.shutdownNow()` so a stopped instance cannot be restarted `[SystemGatewayServer.java:executor]` `[SystemGatewayServer.java:start]` `[SystemGatewayServer.java:stop]`
- `GatewayDispatcher.dispatch` normalizes `null` payloads to an empty `JSONObject` and switches directly on a non-null `command` string `[GatewayDispatcher.java:dispatch]`

## Side Effects
- Creates `<filesDir>/logs` if missing, reads or atomically writes `<filesDir>/logs/gateway.token` with `0600` permissions, and atomically writes the bound port to `<filesDir>/logs/gateway.port` via `AtomicFileWriter.writeText` `[SystemGatewayServer.java:logsDir]` `[SystemGatewayServer.java:loadOrCreateToken]` `[SystemGatewayServer.java:start]`
- Updates static volatile `activePort` on construction and bind, opens and closes a TCP `ServerSocket` on `127.0.0.1`, spawns `"AgyGatewayServer"` and up to 8 client worker threads, and emits Android `Log` messages under tag `"SystemGateway"` `[SystemGatewayServer.java:SystemGatewayServer]` `[SystemGatewayServer.java:start]` `[SystemGatewayServer.java:stop]` `[SystemGatewayServer.java:handleClient]`
- `GatewayDispatcher.dispatch` invokes side-effecting Android handlers and core services (notifications, blocking approval polling, voice service control, URL/WebView automation, wake locks, clipboard, device hardware feedback, shell command execution recorded in `CommandHistory`, and doctor/repair operations) `[GatewayDispatcher.java:dispatch]`
- `GatewayDispatcher.releaseResources` closes the offscreen automation WebView (`WebBrowserAutomationHandler.close()`), releases all held wake locks (`PowerHandler.releaseAll()`), and stops `VoiceForegroundService` when active `[GatewayDispatcher.java:releaseResources]`

# Core Runtime (`com.agy.core`)

## Overview
Manages the lifecycle, supervision, environment, logging, readiness probing, interactive approval/subagent notification callbacks, URL dispatch, and foreground voice session services for the embedded `language_server` core on Android. `CoreServerService` hosts `CoreProcessSupervisor`, `SystemGatewayServer`, `OpenUrlWatcher`, `CoreEventWatcher`, `WakeLockHolder`, and `agy-daemon`, while `ApprovalActionReceiver` bridges Android notification actions back to loopback callbacks and ConnectRPC endpoints and `VoiceForegroundService` maintains active voice sessions.

## Invariants
- `CoreLauncher.killOrphanCoreProcesses()` never kills `Process.myPid()` and only signals `/proc/<pid>` processes whose first 512 bytes of `cmdline` contain `"language_server"` or `"liblanguage_server"`; `launch()` runs `hasRecordedLiveOrStaleCore` (30 ms loopback TCP connect check plus `logs/core.state.json` PID `/proc/<pid>/cmdline` check) so full `/proc` traversal in `killOrphanCoreProcesses()` is skipped when no active or recorded core exists, executes synchronous fail-closed `runtime.installCore()`, and defers `installEnvInBackground()` by 3500 ms on the main Looper only while `CoreRuntimeState.serviceActive` is true `[CoreLauncher.java:killOrphanCoreProcesses]` `[CoreLauncher.java:hasRecordedLiveOrStaleCore]` `[CoreLauncher.java:launch]`
- `CoreEnvironment.apply()` always places `runtime/bin` ahead of `$PREFIX/bin` and inherited `PATH`, preserves `GODEBUG` while ensuring `netdns=go`, sets default mobile Go limits when unset/empty (`GOMEMLIMIT` via `computeGoMemLimitMiB` clamped to `384..1024` MiB at ~25% of device RAM with `512` MiB fallback, `GOGC=75`, and `GOMAXPROCS` via `computeGoMaxProcs` clamped to `2..6` with default `4`), sets `HOME` to `filesDir`, falls back `SHELL` to `/system/bin/sh` when `runtime/bin/bash` is missing/non-executable, and unconditionally removes `LD_LIBRARY_PATH` and `LD_PRELOAD` `[CoreEnvironment.java:apply]` `[CoreEnvironment.java:computeGoMemLimitMiB]` `[CoreEnvironment.java:computeGoMaxProcs]`
- `CoreProcessSupervisor` fails closed without auto-restart on ready timeout (`READY_TIMEOUT_MS = 60000`), pre-ready exit, or launch errors; post-ready unexpected exits auto-restart up to `MAX_RESTARTS = 3` times with `CoreRestartPolicy.delayFor(attempt)` (`min(1000 << min(attempt - 1, 5), 30000)` ms), resetting attempts after `SUSTAINED_READY_MS = 60000` ms uptime `[CoreProcessSupervisor.java:runCoreLoop]` `[CoreRestartPolicy.java:delayFor]` `[CoreRestartPolicy.java:MAX_RESTARTS]` `[CoreRestartPolicy.java:SUSTAINED_READY_MS]`
- `CoreProcessSupervisor` and `CoreServerService` invoke `CoreRuntimeState.notifyStateChanged()` on state transitions (`serverUrl`, `lastError`, `restarting`, `readyGeneration`, and service create/unexpected-stop/destroy resets); `CoreProcessSupervisor` atomically writes `logs/core.state.json` (via `.tmp`, `0600` permissions, `FileDescriptor.sync()`, rename) after `CoreReadyProbe.probeOnce` succeeds, and `streamLog` redacts lines once via `SensitiveDataRedactor.redactLine`, passing `safeLine` to Logcat/`LogRingBuffer`/`CoreLogWriter.writeRedactedLine` (forcing `flushNow` on `"panic:"`, `"fatal"`, `"FATAL"`, `"ERROR"`, `"SIG"`) and `coreEventWatcher.handleRedactedStreamLine` while passing raw `line` to `OpenUrlWatcher` `[CoreProcessSupervisor.java:waitForReady]` `[CoreProcessSupervisor.java:writeCoreStateFile]` `[CoreProcessSupervisor.java:streamLog]` `[CoreRuntimeState.java:notifyStateChanged]`
- `CoreReadyProbe` pins loopback TLS strictly to bundled `res/raw/agy_core_cert` using constant-time SHA-256 digest matching (`MessageDigest.isEqual`) and `LOOPBACK_HOSTNAME_VERIFIER` (allowing only `"127.0.0.1"` or `"localhost"`), pre-checks `isLoopbackPortOpen(port, 50)` before opening an `HttpsURLConnection` (sleeping `RETRY_SLEEP_MS = 25` ms when closed/unready), uses 800 ms connect/read timeouts with redirects disabled, and fails closed if the bundled cert is missing `[CoreReadyProbe.java:isLoopbackPortOpen]` `[CoreReadyProbe.java:probeOnce]` `[CoreReadyProbe.java:configurePinnedLoopbackTls]` `[CoreReadyProbe.java:expectedCertDigest]`

# WebView Bridge (`com.agy.bridge`)

## Overview
Exposes the native Android host bridge to the WebView frontend and serializes engine, theme, and runtime configuration for injection into the trusted top-level document (`window.__APP_CONFIG__`). `AndroidBridge` is the sole class exposing `@JavascriptInterface` methods, gating privileged operations behind a per-instance 256-bit `SecureRandom` hex token while delegating UI, theme, engine state, and configuration concerns to `UiBridge`, `ThemeBridge`, `EngineBridge`, and `EngineConfigJson`.

## Invariants
- Native-only methods (`setActivity`, `isEngineReady`, `getEnginePort`, `getEngineBaseUrl`, `getCsrfToken`, `getConfig`, `getBlobBridgeToken`) are unannotated so embedded WebView frames cannot invoke them to read secrets or engine configuration `[AndroidBridge.java:AndroidBridge]`
- `blobBridgeToken` is generated once per `AndroidBridge` instance from 32 `SecureRandom` bytes encoded as 64 lowercase hex characters; `matchesNativeBridgeToken` fails closed on `null` or exceptions and compares UTF-8 bytes in constant time via `MessageDigest.isEqual` `[AndroidBridge.java:createBlobBridgeToken]` `[AndroidBridge.java:matchesNativeBridgeToken]`
- Unauthorized calls to the 20 token-gated `@JavascriptInterface` methods fail closed: boolean methods return `false`, void methods no-op, account-list methods return `"[]"`, `switchSavedAccount` returns `{"ok":false,"error":"unauthorized"}`, and `readClipboardImage` returns `{"ok":false,"error":"unauthorized"}`; `openLocalPath` and `installLocalApk` additionally resolve targets through `resolveSafeLocalFile` (enforcing `AppFileProvider.isAllowedPath` and normalizing `/sdcard/` prefixes); `showAgentNotification` additionally clamps title/body lengths (120/400 chars), sanitizes tags with `"agy_web_"` prefix, rate-limits duplicate dispatches within `2000` ms, and lazily posts via `NotificationHandler` (`CHANNEL_ALERTS` or silent `CHANNEL_SUBAGENTS`) `[AndroidBridge.java:matchesNativeBridgeToken]` `[AndroidBridge.java:resolveSafeLocalFile]` `[AndroidBridge.java:showAgentNotification]` `[AndroidBridge.java:readClipboardImage]`
- `openLocalPreview` allows only URLs validated by `LocalPreviewDialog.isAllowedLoopbackUrl(url)`; `openRemotePortal` accepts no URL argument and opens only the hardcoded `REMOTE_PORTAL_URL = "https://antigravity.google.com"`; `setSurfaceColor` returns `false` if `ThemeColors.parseHexColor(hexColor)` returns `null` `[AndroidBridge.java:openLocalPreview]` `[AndroidBridge.java:REMOTE_PORTAL_URL]` `[AndroidBridge.java:setSurfaceColor]`
- Activity resolution differs between `AndroidBridge` and `UiBridge`: `AndroidBridge` falls back to `MainActivity.activeActivity` only when `activityRef` itself is `null` (not when a non-null `WeakReference` has been cleared), while `UiBridge` has no static fallback `[AndroidBridge.java:activityRef]` `[UiBridge.java:activityRef]`
- UI-mutating `MainActivity` calls (`onUiReady`, `openDirectoryPicker`, `setSurfaceColor`, `setExtraKeysVisible` activity update, `openLocalPreview`, `openRemotePortal` when `act != null`, `startVoiceDictation`, `stopVoiceDictation`, and `UiBridge.onUiReady`/`onUiError`/`setDesktopMode`) dispatch to the main thread via `runOnUiThread`; all other bridge calls (`ThemeBridge`, `ExtraKeysBarView` prefs, `VoiceForegroundService`, `ClipboardImageReader`, `FileDownloader.handleBlobData`, and `CustomTabLauncher` fallback) execute synchronously on the caller (JS bridge) thread `[AndroidBridge.java:onUiReady]` `[AndroidBridge.java:saveBlob]` `[UiBridge.java:onUiReady]` `[UiBridge.java:onUiError]` `[UiBridge.java:setDesktopMode]`
- `UiBridge.onUiError` redacts `errorMessage` via `SensitiveDataRedactor.redactLine` before logging or displaying fatal error UI `[UiBridge.java:onUiError]`
- `EngineBridge.isReady()` is true iff `CoreRuntimeState.serverUrl != null`; `getBaseUrl()` strips any query string starting at `?` (falling back to `CoreUrl.baseUrl(runtime.getHttpsPort())`); `getCsrfToken()` prefers `CoreRuntimeState.csrfToken` over `runtime.getCsrfToken()` `[EngineBridge.java:isReady]` `[EngineBridge.java:getBaseUrl]` `[EngineBridge.java:getCsrfToken]`
- `EngineConfigJson.get()` catches all `Exception`s and returns `"{}"`, always sets `productName` to `"antigravity-app"`, derives `releaseChannel` as `"dev"` when `RuntimeConfig.DEBUG` is true else `"stable"`, and maps both `filesDir` and `home` to `appContext.getFilesDir().getAbsolutePath()` `[EngineConfigJson.java:get]`
- `ThemeBridge` guards against a null `ThemeManager`, returning `"dark"` from `getTheme()` and `false` from `setTheme`/`setThemeByUser` when `theme == null` `[ThemeBridge.java:getTheme]` `[ThemeBridge.java:setTheme]` `[ThemeBridge.java:setThemeByUser]`

## Side Effects
- Updates volatile `WeakReference<MainActivity>` references on `AndroidBridge` and `UiBridge` `[AndroidBridge.java:setActivity]` `[UiBridge.java:setActivity]`
- Posts UI updates to `MainActivity` (dismiss splash, signal web UI ready, show fatal error, open directory picker, apply surface color, toggle desktop mode and extra-keys bar, open `LocalPreviewDialog`, open remote portal, start/stop voice dictation) `[AndroidBridge.java:onUiReady]` `[AndroidBridge.java:openDirectoryPicker]` `[AndroidBridge.java:setSurfaceColor]` `[AndroidBridge.java:setExtraKeysVisible]` `[AndroidBridge.java:openLocalPreview]` `[AndroidBridge.java:openRemotePortal]` `[AndroidBridge.java:startVoiceDictation]` `[AndroidBridge.java:stopVoiceDictation]` `[UiBridge.java:onUiReady]` `[UiBridge.java:onUiError]` `[UiBridge.java:setDesktopMode]`
- Mutates persisted theme and extra-keys preferences via `ThemeManager` and `ExtraKeysBarView.setVisiblePref`, and launches external browser/Custom Tabs for `REMOTE_PORTAL_URL` when no activity is attached `[AndroidBridge.java:setTheme]` `[AndroidBridge.java:setThemeByUser]` `[AndroidBridge.java:onVisualThemeChanged]` `[AndroidBridge.java:setExtraKeysVisible]` `[AndroidBridge.java:openRemotePortal]` `[ThemeBridge.java:setTheme]`
- Starts, stops, and mutes `VoiceForegroundService`, posts bounded agent notifications via `NotificationHandler`, reads clipboard image payloads via `ClipboardImageReader`, and saves base64 blobs to disk via `FileDownloader.handleBlobData` `[AndroidBridge.java:startVoiceService]` `[AndroidBridge.java:stopVoiceService]` `[AndroidBridge.java:setVoiceMuted]` `[AndroidBridge.java:showAgentNotification]` `[AndroidBridge.java:readClipboardImage]` `[AndroidBridge.java:saveBlob]`
- Emits Android `Log.i` and redacted `Log.e` entries under tag `"AndroidBridge"` `[UiBridge.java:TAG]` `[UiBridge.java:onUiReady]` `[UiBridge.java:onUiError]`

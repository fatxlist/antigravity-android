# com.agy.util

## Overview
Shared Android and JVM utility library supporting file/asset/stream I/O, atomic writes, POSIX permission management, canonical path containment and embedded-core origin checks, log/URL secret redaction, SHA-256 hashing, POSIX shell quoting, Storage Access Framework (SAF) tree-URI resolution, sandboxed `ContentProvider` file sharing (`AppFileProvider`), external URI/Activity dispatch (`UriDispatcher`, `HostActivityResolver`), subprocess draining/waiting, main-thread posting, and WebView layout parameters.

## Interface
- `AppFileProvider` (`public class extends ContentProvider` `[AppFileProvider.java:AppFileProvider]`):
  - ContentProvider overrides: `onCreate()`, `openFile(Uri, String)`, `getType(Uri)`, `query(Uri, String[], String, String[], String)`, `insert(Uri, ContentValues)`, `delete(Uri, String, String[])`, `update(Uri, ContentValues, String, String[])` `[AppFileProvider.java:AppFileProvider]`.
  - `getUriForFile(Context, File)` — builds `content://<packageName>.fileprovider<absolutePath>` `[AppFileProvider.java:getUriForFile]`.
  - `isAllowedPath(String canonicalPath, String filesDirCanonical, String[] allowedRootsCanonical)` — checks canonical root containment and sensitive-path exclusions `[AppFileProvider.java:isAllowedPath]`.
- `AssetPicker` (`public final class`): `pick(AssetManager, String...)` — returns the first openable asset name or `null` `[AssetPicker.java:pick]`.
- `AssetReader` (`public final class`): `readString(Context, String)` — reads an APK asset as UTF-8 or returns `null` on failure `[AssetReader.java:readString]`.
- `AssetUnpacker` (`public final class`): `copyTree(AssetManager, String, File)`, `unpackTree(AssetManager, String, File)`, `copyFile(AssetManager, String, File)` — unpacks APK asset files/directories to disk `[AssetUnpacker.java:copyTree]` `[AssetUnpacker.java:unpackTree]` `[AssetUnpacker.java:copyFile]`.
- `AtomicFileWriter` (`public final class`): `writeText(File, String)`, `writeBytes(File, byte[])` — writes files via sibling temporary files and rename `[AtomicFileWriter.java:writeText]` `[AtomicFileWriter.java:writeBytes]`.
- `CoreUrl` (`public final class`): `startUrl(int)`, `startUrl(int, String)`, `baseUrl(int)` — builds `https://127.0.0.1:<port>` loopback URLs `[CoreUrl.java:startUrl]` `[CoreUrl.java:baseUrl]`.
- `DocumentsContractHelper` (`public final class`): `resolveTreeUriToPath(Context, Uri)`, `resolveDocumentId(String, String, String)` — resolves SAF tree URIs and document IDs to filesystem paths, including Downloads-provider opaque numeric/`msd:` IDs via `ContentResolver` (`_data`, API 29+ MediaStore `relative_path`+`_display_name`, and `Download/<display_name>`) `[DocumentsContractHelper.java:resolveTreeUriToPath]` `[DocumentsContractHelper.java:resolveDocumentId]`.
- `SafPathResolver` (`public final class`): `isNumericId(String)`, `stripRawPrefix(String)`, `stripLeadingSlashes(String)`, `downloadCandidate(File, String, String)`, `candidatesForDocumentId(String, File)`, `firstExisting(File[])` — pure-JVM SAF path mapping and validation helpers `[SafPathResolver.java:isNumericId]` `[SafPathResolver.java:stripRawPrefix]` `[SafPathResolver.java:downloadCandidate]` `[SafPathResolver.java:candidatesForDocumentId]` `[SafPathResolver.java:firstExisting]`.
- `ErrorText` (`public final class`): `describe(Exception)` — returns the exception message or simple class name `[ErrorText.java:describe]`.
- `FileModeUtil` (`public final class`): `recursiveSetReadableExecutable(File)`, `setExec(File)`, `recursiveSetExec(File)`, `applyMode(File, long)`, `copyPermissions(File, File)` — applies and copies POSIX file modes `[FileModeUtil.java:recursiveSetReadableExecutable]` `[FileModeUtil.java:setExec]` `[FileModeUtil.java:recursiveSetExec]` `[FileModeUtil.java:applyMode]` `[FileModeUtil.java:copyPermissions]`.
- `HostActivityResolver` (`public final class`): `EXTRA_CASCADE_ID = "com.agy.EXTRA_CASCADE_ID"`, `sanitizeCascadeId(String)`, `resolve(Context)`, `createOpenIntent(Context)`, `createOpenIntent(Context, String)` — validates optional conversation deep-link IDs, resolves the active or enabled launcher host `Activity` class, and creates its launch `Intent` `[HostActivityResolver.java:EXTRA_CASCADE_ID]` `[HostActivityResolver.java:sanitizeCascadeId]` `[HostActivityResolver.java:resolve]` `[HostActivityResolver.java:createOpenIntent]`.
- `IoUtil` (`public final class`): `pipe(InputStream, OutputStream)`, `readAllBytes(InputStream)`, `readAll(InputStream, String)`, `readFully(InputStream, byte[])`, `closeQuietly(Closeable)`, `deleteQuietly(File)` `[IoUtil.java:pipe]` `[IoUtil.java:readAllBytes]` `[IoUtil.java:readAll]` `[IoUtil.java:readFully]` `[IoUtil.java:closeQuietly]` `[IoUtil.java:deleteQuietly]`.
- `MainThreadPost` (`public final class`): `post(Runnable)` — posts a `Runnable` onto `Looper.getMainLooper()` `[MainThreadPost.java:post]`.
- `MimeTypes` (`public final class`): `isTextMime(String)`, `getMimeType(String)` — classifies text MIME types and maps file extensions to MIME types `[MimeTypes.java:isTextMime]` `[MimeTypes.java:getMimeType]`.
- `PathSafety` (`public final class`): `isInside(File root, File file)` — validates canonical-path containment `[PathSafety.java:isInside]`.
- `ProcessUtils` (`public final class`): `sleep(long)`, `isAlive(Process)`, `exitCode(Process)`, `drainAndWait(Process, long, TimeUnit)` `[ProcessUtils.java:sleep]` `[ProcessUtils.java:isAlive]` `[ProcessUtils.java:exitCode]` `[ProcessUtils.java:drainAndWait]`.
- `SensitiveDataRedactor` (`public final class`): `safeUrl(String)`, `redactLine(String)` — redacts URL credentials/paths/queries and token/auth headers/fields `[SensitiveDataRedactor.java:safeUrl]` `[SensitiveDataRedactor.java:redactLine]`.
- `Sha256` (`public final class`): `of(File)`, `of(InputStream)` — computes lowercase hex SHA-256 digests `[Sha256.java:of]`.
- `ShellQuote` (`public final class`): `quote(String)` — POSIX single-quotes unsafe shell values `[ShellQuote.java:quote]`.
- `StreamDrain` (`public final class`): `drain(InputStream)` — reads and discards all bytes from an `InputStream` `[StreamDrain.java:drain]`.
- `TrustedCoreOrigin` (`public final class`): `matches(Uri, int)` — verifies exact loopback HTTPS core origin `[TrustedCoreOrigin.java:matches]`.
- `UriDispatcher` (`public final class`): `open(Context, String)`, `openDirectory(Context, File)`, `openParentDirectory(Context, File)`, `openFile(Context, File)`, `installApk(Context, File)` — dispatches URLs, files, parent directories, APK install prompts, and generic URIs via `ACTION_VIEW` `[UriDispatcher.java:open]` `[UriDispatcher.java:openDirectory]` `[UriDispatcher.java:openParentDirectory]` `[UriDispatcher.java:openFile]` `[UriDispatcher.java:installApk]`.
- `ViewParams` (`public final class`): `full()` — creates `MATCH_PARENT` x `MATCH_PARENT` `FrameLayout.LayoutParams` `[ViewParams.java:full]`.

## Invariants
- `AppFileProvider` canonicalizes requested paths and enforces containment inside `filesDir`, `cacheDir`, `Environment.getExternalStorageDirectory()`, `getExternalFilesDir(null)`, or `getExternalCacheDir()`, throwing `IllegalArgumentException` on null/unresolvable paths and `SecurityException` on missing context or disallowed paths; `isAllowedPath` unconditionally blocks `<filesDir>/.gemini`, `<filesDir>/logs/gateway.token`, `<filesDir>/logs/core.state.json`, `<filesDir>/logs/approvals.json`, and sibling `<appData>/shared_prefs` and `<appData>/databases` `[AppFileProvider.java:getFileForUri]` `[AppFileProvider.java:isAllowedPath]`.
- `AppFileProvider.openFile` requires `file.exists()` even for write modes (`FileNotFoundException` otherwise) and defaults unrecognized modes to `MODE_READ_ONLY`; `insert`, `delete`, and `update` are disabled no-ops; `query` defaults null projection to `[DISPLAY_NAME, SIZE]` and returns `null` for unknown columns; `getType` returns `vnd.android.document/directory` for directories and `application/octet-stream` as fallback `[AppFileProvider.java:openFile]` `[AppFileProvider.java:insert]` `[AppFileProvider.java:delete]` `[AppFileProvider.java:update]` `[AppFileProvider.java:query]` `[AppFileProvider.java:getType]`.
- `AssetPicker.pick` probes candidates in varargs order swallowing `IOException`; `AssetReader.readString` decodes UTF-8 and maps all exceptions to `null`; `AssetUnpacker.unpackTree` fails closed (`IOException`) when `assets.list(assetDir)` is null or empty before creating `destDir` `[AssetPicker.java:pick]` `[AssetReader.java:readString]` `[AssetUnpacker.java:unpackTree]` `[AssetUnpacker.java:copyTree]`.
- `AtomicFileWriter.writeText` writes UTF-8 to `<target>.tmp`, flushes and fsyncs via `getFD().sync()`, renames over `target` (retrying after `target.delete()`), and cleans up `.tmp` on failure without throwing; `writeBytes` uses a unique sibling temp file, preserves `0777` mode via `FileModeUtil.copyPermissions`, and falls back to an in-place overwrite if rename fails `[AtomicFileWriter.java:writeText]` `[AtomicFileWriter.java:writeBytes]`.
- `CoreUrl` emits `https://127.0.0.1:<port>` and appends `?csrf_token=<token>` only when `csrfToken != null`; `TrustedCoreOrigin.matches` requires non-null `Uri`, case-insensitive `https` scheme, exact `127.0.0.1` host, `getUserInfo() == null`, and `getPort() == expectedPort` `[CoreUrl.java:startUrl]` `[CoreUrl.java:baseUrl]` `[TrustedCoreOrigin.java:matches]`.
- `DocumentsContractHelper.resolveDocumentId` rejects null/empty inputs, `msd:` volumes, and opaque Downloads provider IDs (`msd:*` or `\\d+`) by returning `null`, mapping `raw:`, Downloads `downloads`/`root`, `primary:`, `home:`, and `<volume>:` to filesystem paths; `resolveTreeUriToPath` checks `File.exists()` only for non-primary-root paths and maps any `Throwable` to `null` `[DocumentsContractHelper.java:resolveDocumentId]` `[DocumentsContractHelper.java:resolveTreeUriToPath]`.
- `FileModeUtil.recursiveSetReadableExecutable` and `recursiveSetExec` skip symlinks via `TextFileDetector.isSymlink`; `setExec` is a no-op if `file == null || !file.exists()`; `applyMode` masks POSIX bits with `0777L` and forces directory execute bits on Java fallback; `copyPermissions` copies only `st_mode & 0777` `[FileModeUtil.java:recursiveSetReadableExecutable]` `[FileModeUtil.java:recursiveSetExec]` `[FileModeUtil.java:setExec]` `[FileModeUtil.java:applyMode]` `[FileModeUtil.java:copyPermissions]`.
- `HostActivityResolver.resolve` selects in strict precedence: live `MainActivity.activeActivity` (`!isFinishing() && !isDestroyed()`) -> `LauncherLightActivity` if explicitly enabled -> `LauncherDarkActivity` if not disabled -> `MainActivity.class`; `sanitizeCascadeId` rejects strings outside `[A-Za-z0-9_.-]{1,128}` (`null` otherwise); `createOpenIntent` always sets `ACTION_MAIN` and `FLAG_ACTIVITY_NEW_TASK | FLAG_ACTIVITY_SINGLE_TOP | FLAG_ACTIVITY_CLEAR_TOP` and attaches `EXTRA_CASCADE_ID` only when `sanitizeCascadeId(cascadeId)` is non-null `[HostActivityResolver.java:resolve]` `[HostActivityResolver.java:sanitizeCascadeId]` `[HostActivityResolver.java:createOpenIntent]`.
- `IoUtil.pipe`, `IoUtil.readAllBytes`, `StreamDrain.drain`, and `Sha256.of(InputStream)` terminate on `read <= 0` and leave caller streams open; `IoUtil.readFully` stops only when the buffer fills or `read < 0`; `PathSafety.isInside` compares canonical paths by exact equality or `rootPath + File.separator` prefix `[IoUtil.java:pipe]` `[IoUtil.java:readAllBytes]` `[IoUtil.java:readFully]` `[StreamDrain.java:drain]` `[Sha256.java:of]` `[PathSafety.java:isInside]`.
- `MimeTypes.isTextMime` accepts only `text/*`, `application/javascript`, `application/json`, and `image/svg+xml`; `getMimeType` defaults `null` and unknown extensions to `application/octet-stream` `[MimeTypes.java:isTextMime]` `[MimeTypes.java:getMimeType]`.
- `ProcessUtils.sleep` and `drainAndWait` restore the thread interrupt flag on `InterruptedException`; `exitCode` returns `-1` while alive; `drainAndWait` drains and closes `p.getInputStream()` before waiting `[ProcessUtils.java:sleep]` `[ProcessUtils.java:exitCode]` `[ProcessUtils.java:drainAndWait]`.
- `SensitiveDataRedactor.safeUrl` strips userinfo, path, query, and fragment to `<scheme>://<host>[:<port>]/<redacted>` (or `<url>` when invalid); `redactLine` short-circuits URL matching when `"://"` is absent and skips `SECRET_FIELD` / `SENSITIVE_HEADER` (`authorization`/`cookie`) / `BEARER` regexes via zero-allocation `mightContainSensitiveField` substring probes when no keyword matches (applying them in order when matched); `ShellQuote.quote` leaves only `[A-Za-z0-9_./:=+-]+` unquoted `[SensitiveDataRedactor.java:safeUrl]` `[SensitiveDataRedactor.java:redactLine]` `[SensitiveDataRedactor.java:mightContainSensitiveField]` `[ShellQuote.java:quote]`.
- `UriDispatcher.open` suppresses `http`/`https` URLs containing `googleapis.com/oauth2/v2/userinfo`, `googleapis.com/auth`, or `daily-cloudcode-pa.googleapis.com` (returning `false`), routes existing `file://` or `/`-prefixed paths to `openDirectory`/`openFile`, falls back in `openDirectory` from `AppFileProvider` (`vnd.android.document/directory`) to `Uri.fromFile` (`resource/folder`), and `installApk` opens `application/vnd.android.package-archive` `AppFileProvider` URIs cleanly with `FLAG_GRANT_READ_URI_PERMISSION` (`openParentDirectory` targets a file's existing parent directory) `[UriDispatcher.java:open]` `[UriDispatcher.java:openDirectory]` `[UriDispatcher.java:openParentDirectory]` `[UriDispatcher.java:openFile]` `[UriDispatcher.java:installApk]`.

## Side Effects
- Opens `ParcelFileDescriptor` handles (including `MODE_CREATE` for write modes) and runs filesystem canonicalization/`stat` calls `[AppFileProvider.java:openFile]` `[AppFileProvider.java:getFileForUri]` `[AppFileProvider.java:getType]` `[AppFileProvider.java:query]`.
- Reads APK assets via `AssetManager`, creates directories (`File.mkdirs`), writes/overwrites files on disk (`FileOutputStream`), fsyncs temp files (`FileDescriptor.sync`), renames/deletes files, and copies or mutates POSIX modes (`Os.chmod`, `Os.stat`, `File.setReadable`/`setWritable`/`setExecutable`) `[AssetPicker.java:pick]` `[AssetReader.java:readString]` `[AssetUnpacker.java:copyTree]` `[AssetUnpacker.java:copyFile]` `[AtomicFileWriter.java:writeText]` `[AtomicFileWriter.java:writeBytes]` `[FileModeUtil.java:applyMode]` `[FileModeUtil.java:copyPermissions]` `[FileModeUtil.java:setExec]`.
- Reads `Environment.getExternalStorageDirectory()`, `File.exists()`, `File.getCanonicalPath()`, `MainActivity.activeActivity`, `PackageManager.getComponentEnabledSetting`, and `ContentResolver.getType` `[DocumentsContractHelper.java:resolveTreeUriToPath]` `[PathSafety.java:isInside]` `[HostActivityResolver.java:resolve]` `[UriDispatcher.java:openFile]`.
- Consumes/writes streams, closes `Closeable` handles, deletes files (`IoUtil.deleteQuietly`), opens files for SHA-256 hashing (`Sha256.of`), blocks threads and drains/waits on child `Process` instances, and sets thread interrupt status `[IoUtil.java:pipe]` `[IoUtil.java:closeQuietly]` `[IoUtil.java:deleteQuietly]` `[Sha256.java:of]` `[StreamDrain.java:drain]` `[ProcessUtils.java:sleep]` `[ProcessUtils.java:drainAndWait]`.
- Posts `Runnable` tasks to Android's main UI thread via `Handler(Looper.getMainLooper())`, launches external Android activities via `Context.startActivity` (with `FLAG_ACTIVITY_NEW_TASK` and `FLAG_GRANT_READ_URI_PERMISSION`), and writes warning logs via `android.util.Log.w` `[MainThreadPost.java:post]` `[UriDispatcher.java:open]` `[UriDispatcher.java:openDirectory]` `[UriDispatcher.java:openFile]` `[DocumentsContractHelper.java:resolveTreeUriToPath]` `[FileModeUtil.java:recursiveSetReadableExecutable]`.

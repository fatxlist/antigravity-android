# src

## Overview
Source tree for the Antigravity Android host application, separating production manifest/resources/Java code (`main/`) from host JVM unit tests (`test/`).

## Subdirectories & Boundaries
- `main`: [./main/README.md](./main/README.md) - Production Android manifest (`AndroidManifest.xml`), resources (`res/`), and Java implementation (`java/`).

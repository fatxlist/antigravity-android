# Bridge Core (`web/src/core`)

## Overview
Core runtime transport and environment compatibility layer concatenated via `web/src.manifest` into `bridge.core.js` (`v1.2.1`). It installs Android WebView shims (`Navigator.prototype.onLine`, `Notification`, `window.process`), merges `window.__APP_CONFIG__`, synchronizes CSRF tokens and cookies, discovers ConnectRPC endpoints, rewrites relative/`file://` RPC and `/voice/health` `fetch` calls with startup retries, and wraps streaming ConnectRPC responses for host-resume recovery.

## Interface
- `[public-api.js:window.__agBridgeCore]` Public API object exposing `{ version, config, endpoints, endpoint, setEndpoint, baseOrigin, syncCsrf, parseEndpointSpec, triggerStreamRecovery, getActiveStreamCount, notifyNetworkFailure, notifyNetworkSuccess }`.
- `[public-api.js:api.version]` / `[namespace.js:VERSION]` Version string constant `'1.2.1'`.
- `[public-api.js:api.config]` / `[config.js:window.__APP_CONFIG__]` Live merged configuration object (`productName`, `appName`, `appVersion`, `version`, `isStandalone`, `platform`, `arch`, `enginePort`, `engineReady`, `apiPrefix`, `csrfToken`, `csrf_token`, `workspaceRoot`, `activeCascadeId`, `devMode`, plus pre-injected own keys).
- `[public-api.js:api.endpoints]` / `[endpoints.js:global.__AG_ENDPOINTS__]` Live endpoint map populated from `window.__AG_ENDPOINTS__` and URL query parameters (`endpoints`, `ag_endpoints`, `port`, `enginePort`).
- `[public-api.js:api.endpoint]` / `[public-api.js:api.setEndpoint]` / `[public-api.js:api.baseOrigin]` / `[public-api.js:api.parseEndpointSpec]` Endpoint lookup (`[endpoints.js:endpoint]`), mutation (`[endpoints.js:setEndpoint]`), origin resolution (`[endpoints.js:baseOrigin]`), and object/JSON/base64-JSON/delimited `k=v` parser (`[endpoints.js:parseEndpointSpec]`).
- `[public-api.js:api.syncCsrf]` / `[csrf.js:syncCsrf]` Resolves the CSRF token, updates `CONFIG.csrfToken`/`CONFIG.csrf_token` and `csrfToken`/`csrf_token` cookies, and returns the active token.
- `[public-api.js:api.triggerStreamRecovery]` / `[public-api.js:api.getActiveStreamCount]` Triggers loopback streaming RPC teardown/reconnect (`[resume-stream-recovery.js:triggerStreamRecovery]`) and reports `[resume-stream-recovery.js:activeStreamClosers]` count.
- `[namespace.js:window.__agCore]` / `[namespace.js:window.__AG_BRIDGE_CORE__]` / `[fetch-rewrite.js:global.__AG_FETCH_REWRITE__]` Global namespace and idempotency guard flags on `window`.
- `[online-and-notifications.js:Navigator.prototype.onLine]` / `[online-and-notifications.js:global.addEventListener]` / `[online-and-notifications.js:global.Notification]` WebView online getter (always `true`), `'offline'` listener filter, and `FakeNotification` fallback polyfill (`permission = 'granted'`) forwarding `(token, title, body, tag, silent)` to `Android.showAgentNotification`.
- `[polyfills-process.js:window.process]` POSIX-like `process` stub (`platform: 'linux'`, `arch: 'arm64'`, `type: 'renderer'`, `browser: true`, `env`, `versions`, `cwd()`, `nextTick()`).
- `[resume-stream-recovery.js:global.setTimeout]` / `[fetch-rewrite.js:global.fetch]` Wrapped timer (post-resume reconnect acceleration) and wrapped `fetch` (RPC origin rewrite, CSRF injection, startup/voice-health retries, and streaming recovery).
- `[csrf.js:readCsrf]` / `[resume-stream-recovery.js:triggerStreamRecovery]` Consumes `window.__AG_CSRF__`, `meta[name="csrf-token"]` / `meta[name="csrfToken"]`, window `'agy:host-resume'`, and document `'visibilitychange'` events.

## Invariants
- `[namespace.js:window.__AG_BRIDGE_CORE__]` / `[fetch-rewrite.js:global.__AG_FETCH_REWRITE__]` Top-level IIFE executes at most once per `window` when `__AG_BRIDGE_CORE__` is set, and `[fetch-rewrite.js:installFetchRewrite]` wraps `global.fetch` only when `__AG_FETCH_REWRITE__` is falsy and `global.fetch` is a function.
- `[online-and-notifications.js:Navigator.prototype.onLine]` / `[online-and-notifications.js:global.addEventListener]` / `[online-and-notifications.js:global.Notification]` `navigator.onLine` always returns `true`, `'offline'` listeners are never registered on `window`, and `FakeNotification` is installed only when `global.Notification` is undefined (invoking `window.Android.showAgentNotification` when token-authenticated bridge is present).
- `[polyfills-process.js:window.process]` Never overwrites existing truthy properties on `window.process`; `env.NODE_ENV` reflects pre-existing `CONFIG.devMode`, while `cwd()` lazily reads live `CONFIG.workspaceRoot` (fallback `'/'`).
- `[config.js:window.__APP_CONFIG__]` Pre-injected own properties on `window.__APP_CONFIG__` override defaults; `workspaceRoot` resolves `CONFIG.workspaceRoot` -> `window.process.env.HOME` -> `'/storage/emulated/0'`.
- `[csrf.js:readCsrf]` / `[csrf.js:generateFallbackCsrf]` CSRF precedence is strictly `window.__AG_CSRF__` -> `meta[name="csrf-token"]`/`meta[name="csrfToken"]` -> `CONFIG.csrfToken` -> memoized `[csrf.js:generatedCsrfFallback]` (`crypto.randomUUID()` -> 16-byte `crypto.getRandomValues` hex -> 32-char `Math.random()` hex).
- `[endpoints.js:ENDPOINTS]` / `[endpoints.js:baseOrigin]` / `[endpoints.js:coreBase]` Query params `?endpoints=`/`?ag_endpoints=` overwrite pre-existing keys and `?port=`/`?enginePort=` sets `core_http = 'https://127.0.0.1:' + port` and `enginePort = port`; `baseOrigin()` resolves `CONFIG.engineBaseUrl` -> `ENDPOINTS.core` -> `ENDPOINTS.core_https` -> `CONFIG.apiPrefix` -> `ENDPOINTS.core_http` -> `'https://127.0.0.1:' + CONFIG.enginePort` -> `'https://127.0.0.1:' + ENDPOINTS.enginePort` -> `''`, while `coreBase()` guarantees a non-empty origin defaulting to port `45157`.
- `[endpoints.js:setEndpoint]` / `[endpoints.js:ensureCsrf]` / `[endpoints.js:appendCsrfQuery]` `setEndpoint` ignores falsy `name` or nullish `value`; `ensureCsrf` adds `x-codeium-csrf-token` only when absent; `appendCsrfQuery` appends `csrf_token` only when not already present.
- `[resume-stream-recovery.js:global.setTimeout]` / `[resume-stream-recovery.js:triggerStreamRecovery]` Fast-forwards exact `1000ms` timers to `40ms` only within `3000ms` of `lastResumeTs` (internal startup retries bypass this via `[resume-stream-recovery.js:origSetTimeout]`); non-forced recovery debounces within `300ms`, `'agy:host-resume'` forces recovery and cancels pending `visibilitychange` recovery (`150ms` delay, gated by `> 500ms` since `lastHostResumeTs`), and only streams with `entry.openedAt <= now` are closed.
- `[resume-stream-recovery.js:isStreamingRpc]` / `[resume-stream-recovery.js:isLoopbackRpcUrl]` / `[resume-stream-recovery.js:wrapStreamingFetch]` Streaming detection requires `('/exa.' || '/jetski.' || 'Service/')` and `('Stream' || 'Subscribe')` (plus `http(s)://(127.0.0.1|localhost)` for loopback URLs); `wrapStreamingFetch` allocates a single `resumeInterrupter` Promise and `resolveResumeOnce` per stream (raced in `pull()`), closes resume-interrupted streams cleanly (`controller.close()`), and always deletes their closer from `activeStreamClosers`.
- `[fetch-rewrite.js:rpcPathFrom]` / `[fetch-rewrite.js:isVoiceHealthUrl]` / `[fetch-rewrite.js:isRetrySafeCall]` / `[fetch-rewrite.js:fetchWithStartupRetry]` / `[fetch-rewrite.js:fetchVoiceHealthWithRetry]` RPC rewriting matches `[fetch-rewrite.js:RPC_MARKERS]` (`exa.language_server_pb.`, `exa.host_bridge_pb.`, `/exa.`, `/jetski.`) only on non-`http(s):`/`blob:`/`data:`/`ws(s):`/`chrome-extension:` URLs; mutating POST RPCs receive `0` retries while safe `GET`/`HEAD`/`OPTIONS`, streaming RPCs, and `Get|List|Check|Heartbeat|Stream|Subscribe*` paths retry up to `30` times at `120ms` (never retrying aborted calls); `/voice/health` retries up to `15` times at `300ms` on HTTP `502`/`503`/`504` or non-aborted network errors.
- `[fetch-rewrite.js:global.fetch]` Rewritten `Request`-object RPC calls force `credentials: 'omit'`, default method to `'POST'`, and preserve non-empty cloned `arrayBuffer` bodies when `init.body` is undefined.

## Side Effects
- `[namespace.js:window.__agCore]` / `[namespace.js:window.__AG_BRIDGE_CORE__]` / `[public-api.js:window.__agBridgeCore]` Mutates `window` with `__agCore`, `__AG_BRIDGE_CORE__`, and `__agBridgeCore`, and logs readiness to `console.log`.
- `[online-and-notifications.js:Navigator.prototype.onLine]` / `[online-and-notifications.js:global.addEventListener]` / `[online-and-notifications.js:global.Notification]` Redefines `Navigator.prototype.onLine`, wraps `window.addEventListener`, and installs `FakeNotification` when `Notification` is absent.
- `[polyfills-process.js:window.process]` / `[config.js:window.__APP_CONFIG__]` / `[endpoints.js:global.__AG_ENDPOINTS__]` Mutates `window.process`, replaces `window.__APP_CONFIG__`, and writes `window.__AG_ENDPOINTS__`.
- `[csrf.js:syncCsrf]` Mutates `CONFIG.csrfToken` / `CONFIG.csrf_token` and writes `csrfToken` and `csrf_token` cookies (`path=/; SameSite=Lax`) to `document.cookie` at load time and on rewritten RPC calls.
- `[resume-stream-recovery.js:global.setTimeout]` / `[resume-stream-recovery.js:triggerStreamRecovery]` / `[resume-stream-recovery.js:wrapStreamingFetch]` / `[resume-stream-recovery.js:notifyNetworkFailure]` Wraps `window.setTimeout`, attaches `'agy:host-resume'`, `'visibilitychange'`, `'offline'`, and `'online'` listeners, mounts/updates status banner `#ag-net-banner` during network interruptions with exponential backoff (`1500`ms to `12000`ms, max `12` attempts), cancels active stream readers (`'agy:host-resume'`), aborts internal `AbortController`s, replaces streaming `Response.body` streams, and dispatches synthetic `'online'` and `'focus'` events on `window`.
- `[fetch-rewrite.js:installFetchRewrite]` / `[fetch-rewrite.js:global.fetch]` Wraps `window.fetch`, sets `window.__AG_FETCH_REWRITE__ = true`, rewrites network destinations to `coreBase()`, injects CSRF headers/query parameters, and performs retry network requests.

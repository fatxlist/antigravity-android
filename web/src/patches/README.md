# Web Runtime Patches (`web/src/patches`)

## Overview
Feature-scoped Android WebView runtime patches compiled by `web/build.sh` via `web/src.manifest` into standalone IIFE bundles under `web/generated/patches/`. Each subdirectory owns an isolated mobile integration concern: persistent multi-account vault/Settings switcher (`account_switcher`), Android host bridge controls/voice/share/clipboard/local path cards (`mobile_bridge`), splash-screen readiness and startup error forwarding (`startup_ready`), DOM-to-Android theme and surface color synchronization (`theme_sync`), touch adaptation for Base UI model effort menus (`touch_model_menu`), and IME/scroll/focus/audio/BiDi/viewport/media optimizations (`web_optimizations`).

## Subdirectories & Boundaries
- `account_switcher`: [./account_switcher/README.md](./account_switcher/README.md) - Concatenated `patches/account_switcher.js` IIFE exposing `window.__agAccountSwitcher` (`syncProfile`, `renderSection`, `renderScreen`, `listAccounts`) backed by `AccountVaultStore` (`window.Android.*`).
- `mobile_bridge`: [./mobile_bridge/README.md](./mobile_bridge/README.md) - Concatenated `patches/mobile_bridge.js` IIFE exposing `window.__agMobileBridge` and `window.__ag*` native callbacks for Android Share Sheet delivery, Extra-Keys dispatching, `VoiceForegroundService`/`SpeechRecognizer` hooks, native clipboard image pasting, clickable local path/APK cards, and injected Settings "Android Tools" controls.
- `startup_ready`: [./startup_ready/README.md](./startup_ready/README.md) - Concatenated `patches/startup_ready.js` IIFE exposing `window.__agStartupReady` to detect initial `#root` rendering or `[ConversationLoad]` logs, fire one-shot `Android.onUiReady`, and forward pre-ready errors to `Android.onUiError`.
- `theme_sync`: [./theme_sync/README.md](./theme_sync/README.md) - Concatenated `patches/theme_sync.js` IIFE exposing `window.__agThemeSync` to resolve light/dark theme, mirror it to `documentElement` and `<meta name="color-scheme">`, and synchronize visual theme and opaque surface hex colors back to `window.Android`.
- `touch_model_menu`: [./touch_model_menu/README.md](./touch_model_menu/README.md) - Concatenated `patches/touch_model_menu.js` IIFE exposing `window.__agTouchModelMenu` to adapt hover-driven model effort submenus on touch devices via capture-phase tap interception, synthetic pointer events, and `ArrowRight` fallback.
- `web_optimizations`: [./web_optimizations/README.md](./web_optimizations/README.md) - Concatenated `patches/web_optimizations.js` IIFE exposing `window.__agWebOptimizations` and `__agSetImeAnimating`/`__agIsImeAnimating` for IME resize deferral, passive/filtered event listeners, contenteditable focus guards, lazy 48kHz audio gating, safe-area/BiDi CSS injection, and `--agy-vvh` viewport syncing.

# Mobile Bridge (`web/src/patches/mobile_bridge`)

## Overview
Android mobile integration layer concatenated via `web/src.manifest` into `patches/mobile_bridge.js`. It bridges native Android features into the WebView SPA: Share Sheet payload ingestion with a fallback paste banner, Extra-Keys Bar key/ANSI dispatching for xterm and chat composers, `VoiceForegroundService` and native `SpeechRecognizer` integration with `/voice/ws` and mic-track hooks, native clipboard image pasting, and the injected Settings "Android Tools" card / programmatic modal drawer.

## Interface
- `[public-api.js:window.__agMobileBridge]` Public global bridge API exposing `__installed: true`, share/extra-keys/navigation/host methods (`deliverSharedPayload`, `openConversation`, `dispatchExtraKey`, `applyBufferedShare`, `isDesktopMode`, `setDesktopMode`, `isExtraKeysVisible`, `setExtraKeysVisible`, `openLocalPreview`, `openRemotePortal`, `probe`), voice methods (`deliverVoiceText`, `onVoiceDictationStateChanged`, `onVoiceServiceStateChanged`, `startVoiceDictation`, `stopVoiceDictation`, `startVoiceService`, `stopVoiceService`, `setVoiceMuted`, `isVoiceServiceActive`), image paste methods (`deliverPastedImage`, `pasteImageFromClipboard`), and UI controls (`openDrawer`, `closeDrawer`, `toggleDrawer`, `injectSettingsControls`).
- `[public-api.js:window.__agMobileBridge.probe]` Returns diagnostic snapshot `{ installed, uiMounted, drawerOpen, hasPendingShare, shareDeliveries, extraKeyDispatches, voiceDeliveries, imagePastes, dictating, voiceServiceActive, voiceServiceMuted, voiceWsState, voiceLastError, voiceMicLevel, activeVoiceSockets, desktopMode, extraKeysVisible, hasComposer, hasAndroid }`.
- `[public-api.js:window.__agDeliverSharedPayload]` / `[public-api.js:window.__agOpenConversation]` / `[public-api.js:window.__agExtraKey]` / `[public-api.js:window.__agExtraKeysVisibilityChanged]` / `[public-api.js:window.__agDeliverVoiceText]` / `[public-api.js:window.__agVoiceDictationStateChanged]` / `[public-api.js:window.__agVoiceServiceStateChanged]` / `[public-api.js:window.__agDeliverPastedImage]` Top-level `window` callback aliases invoked by native Android (draining startup `window.__AG_PENDING_SHARED_PAYLOAD__` and `window.__AG_PENDING_CASCADE_ID__`).
- `[config.js:STORAGE_KEYS]` / `[config.js:PREVIEW_PRESETS]` / `[config.js:state]` Shared IIFE localStorage keys (`ag_desktop_mode`, `ag_extra_keys_visible`, `ag_mb_pill_top`, `ag_mb_preview_port`), localhost preview port presets (`[3000, 5173, 8000, 8080]`), and runtime state container (`voiceWsState`, `voiceLastError`, `voiceMicLevel`).
- `[config.js:getAndroid]` / `[config.js:getNativeToken]` / `[config.js:triggerLocalPreview]` / `[config.js:triggerRemotePortal]` Consumes `window.Android || window.AndroidBridge`, `window.__AG_NATIVE_BRIDGE_TOKEN__`, and native methods `isDesktopMode`, `setDesktopMode`, `isExtraKeysVisible`, `setExtraKeysVisible`, `openLocalPreview(token, url)`, and `openRemotePortal(token)`.
- `[composer.js:findComposer]` / `[composer.js:insertTextIntoEditable]` Discovers non-bridge, non-terminal editable composers (`TEXTAREA`, `INPUT`, `contentEditable`, `[role="textbox"]`) and performs React/Lexical-safe text insertion.
- `[share.js:deliverSharedPayload]` / `[share.js:applyBufferedShare]` Parses and formats Android Share Sheet payloads, inserts into the active composer, or stages a `#ag-mb-share-banner` / clipboard fallback.
- `[extra_keys.js:dispatchExtraKey]` Normalizes key aliases (`[extra_keys.js:KEY_ALIASES]`, `[extra_keys.js:SPECIAL_KEY_META]`, `[extra_keys.js:CHAR_CODE_MAP]`) and routes synthetic keyboard/ANSI events to xterm (`[extra_keys.js:sendToTerminal]`) or chat/document (`[extra_keys.js:sendToChatOrDocument]`).
- `[voice.js:installVoiceWebSocketHook]` / `[voice.js:installMicTrackObserver]` / `[voice.js:installMicrophonePermissionShim]` / `[voice.js:attachMicLevelMeter]` / `[voice.js:formatVoiceMicError]` / `[voice.js:deliverVoiceText]` / `[voice.js:onVoiceServiceStateChanged]` Wraps `global.WebSocket` (`/voice/ws` via direct `new NativeWS(...)`), `navigator.mediaDevices.getUserMedia` (metering mic RMS to `#ag-mb-voice-level-fill` and reporting user-actionable errors via `voiceLastError` / `#ag-mb-voice-diag` / toast), and `navigator.permissions.query({name:'microphone'})` (bridging WebView false `'denied'` using `android.getMicrophonePermissionState()`), synchronizes native voice service/dictation calls, and dispatches `CustomEvent('ag-voice-service-state')`.
- `[clipboard_image.js:deliverPastedImage]` / `[clipboard_image.js:pasteImageFromNativeClipboard]` / `[clipboard_image.js:installClipboardImageInterceptor]` Decodes base64 or native clipboard images (`android.readClipboardImage(token)` / `android.hasClipboardImage()`) and delivers them via synthetic `paste` (`__agSyntheticPaste`), `drop` (`__agSyntheticDrop`), or `input[type="file"]`.
- `[controls.js:mountQuickControls]` / `[controls.js:tryInjectSettingsSection]` / `[controls.js:setDrawerOpen]` / `[controls.js:showBridgeToast]` Manages `<style id="ag-mb-styles">`, injected Settings card `#ag-mb-settings-section`, programmatic modal drawer `#ag-mb-drawer`, and status toast `#ag-mb-toast`.

## Invariants
- `[config.js:window.__agMobileBridge.__installed]` / `[public-api.js:state.installed]` Single-install guards prevent duplicate top-level IIFE evaluation and re-entry in `[public-api.js:installMobileBridge]`.
- `[config.js:normalizeLocalPreviewUrl]` / `[config.js:triggerLocalPreview]` / `[config.js:triggerRemotePortal]` Local preview URLs must resolve to `http:` or `https:` with hostname `localhost` or `127.0.0.1` (bare ports restricted to `1..65535`); all mutating native bridge calls (`openLocalPreview`, `openRemotePortal`, voice controls, `readClipboardImage`) pass `getNativeToken()` as their first argument.
- `[composer.js:isEditableElement]` / `[composer.js:isElementVisible]` / `[composer.js:findComposer]` Excludes bridge elements (`[data-ag-mobile-bridge="true"]`), terminal nodes (`.xterm-helper-textarea`, `.xterm`, `.xterm-screen`, `[data-terminal="true"]`), disabled/read-only controls, and hidden/small (`<= 8px`) nodes; prioritizes active editable -> `state.lastEditable` -> highest-scored DOM candidate.
- `[composer.js:setNativeControlValue]` / `[composer.js:insertIntoContentEditable]` Uses native prototype value setters so React controlled inputs update, only prepends `separatorIfNonEmpty` when preceding text lacks trailing whitespace, and aborts manual Range DOM writes if a cancelable `beforeinput` event is cancelled.
- `[share.js:formatSharedPayload]` / `[public-api.js:openConversation]` / `[public-api.js:installMobileBridge]` Omits share `subject` when already contained in `text`, rejects empty payloads without incrementing `state.shareDeliveries`, validates `openConversation(cascadeId)` against `/^[A-Za-z0-9_.-]{1,128}$/` navigating via `history.pushState(null, '', '/c/' + encodeURIComponent(id))` + `'ag-open-conversation'`, and clears `window.__AG_PENDING_SHARED_PAYLOAD__` / `window.__AG_PENDING_CASCADE_ID__` before delivering stashed startup values.
- `[extra_keys.js:resolveKeyMeta]` / `[extra_keys.js:findActiveTerminalTextarea]` / `[extra_keys.js:sendToTerminal]` Maps `Ctrl+A..Z` to `\x01..\x1a` and punctuation control chords to `\x1b..\x1f`, targets `state.lastTerminal` only when visible and `document.activeElement` is not an editable composer, skips ANSI/composer/Escape fallback if `keydown` is cancelled, and resets the xterm helper textarea back to `''`.
- `[voice.js:installVoiceWebSocketHook]` / `[voice.js:installMicTrackObserver]` / `[voice.js:installMicrophonePermissionShim]` / `[voice.js:trackVoiceSocket]` / `[voice.js:onVoiceServiceStateChanged]` Global hooks are idempotent (`__agVoiceWrapped` / `__agMicWrapped`), preserve `NativeWS.prototype` and ready-state constants, construct `NativeWS` directly, map false WebView `microphone` `'denied'` states to native `'granted'`/`'prompt'` without affecting other permissions, auto-start native voice on the first open `/voice/ws` socket and auto-stop when the last closes, surface abnormal WS close codes (`!== 1000 && !== 1005`), WS errors, and `getUserMedia` errors into `state.voiceLastError` / `#ag-mb-voice-diag` / toast, attach RMS metering to `#ag-mb-voice-level-fill`, deduplicate/prune ended tracks in `state.activeMicTracks`, force `voiceServiceMuted = false` when inactive, and close tracked sockets (`1000`, `'stopped_from_notification'`) on native stop.
- `[voice.js:deliverVoiceText]` / `[voice.js:stopNativeVoiceDictation]` Truncates interim toast text over 64 chars to 61 + `'…'`, falls back to `deliverSharedPayload` if no composer is mounted on final text, and always clears `state.dictating` and `state.voiceInterim` on stop.
- `[clipboard_image.js:sanitizeImageMime]` / `[clipboard_image.js:deliverPastedImage]` / `[clipboard_image.js:installClipboardImageInterceptor]` Normalizes invalid/empty/`image/*` MIME types to `'image/png'`, attempts attachment strictly in `paste -> drop -> file_input` order stopping at the first handled path, installs capture-phase `paste` interception once (`state.pasteInterceptorInstalled`), and ignores synthetic pastes, bridge/terminal targets, existing image pastes, and text pastes when `hasNativeClipboardImage()` is false.
- `[controls.js:tryInjectSettingsSection]` / `[controls.js:setDrawerOpen]` / `[controls.js:findSettingsInjectionHost]` Never mounts `#ag-mb-settings-section` and `#ag-mb-drawer` simultaneously so child `#ag-mb-*` IDs remain unique, marks all bridge containers with `data-ag-mobile-bridge="true"`, never auto-mounts a floating pill overlay, and injects into Settings only when non-bridge `.agy-card` context text matches both Appearance/Application and settings keywords.

## Side Effects
- `[public-api.js:window.__agMobileBridge]` / `[public-api.js:installMobileBridge]` Publishes `window.__agMobileBridge` and seven `window.__ag*` native callback aliases, registers a capture-phase `focusin` listener (`[public-api.js:installFocusTracking]`), and clears `window.__AG_PENDING_SHARED_PAYLOAD__`.
- `[voice.js:installVoiceWebSocketHook]` / `[voice.js:installMicTrackObserver]` / `[voice.js:installMicrophonePermissionShim]` / `[voice.js:onVoiceServiceStateChanged]` Monkey-patches `window.WebSocket`, `navigator.mediaDevices.getUserMedia`, and `navigator.permissions.query` synchronously on load (and in `installMobileBridge`), toggles `MediaStreamTrack.enabled`, closes `/voice/ws` sockets on native stop, and dispatches `CustomEvent('ag-voice-service-state')` on `window`.
- `[config.js:setDesktopModeState]` / `[config.js:setExtraKeysState]` / `[controls.js:buildAndroidToolsCard]` Reads and writes `localStorage` (`ag_desktop_mode`, `ag_extra_keys_visible`, `ag_mb_preview_port`) and invokes `window.Android` desktop mode, extra-keys, preview, remote portal, voice, and clipboard methods.
- `[composer.js:insertIntoTextControl]` / `[composer.js:insertIntoContentEditable]` / `[extra_keys.js:dispatchExtraKey]` Focuses editors/terminals, mutates input values/contentEditable DOM/Selection, and dispatches synthetic `keydown`, `keypress`, `beforeinput`, `input`, `change`, and `keyup` events.
- `[share.js:showShareBanner]` / `[share.js:applyBufferedShare]` Mounts/removes `#ag-mb-share-banner` on `document.body` and may write to `navigator.clipboard.writeText(...)` as a composerless fallback.
- `[clipboard_image.js:installClipboardImageInterceptor]` / `[clipboard_image.js:deliverPastedImage]` Attaches a capture-phase `paste` listener on `document`, dispatches synthetic `ClipboardEvent('paste')`/`DragEvent('drop')`, or mutates `input[type="file"].files` with a bubbling `'change'` event.
- `[controls.js:ensureBridgeStyles]` / `[controls.js:mountQuickControls]` / `[controls.js:showBridgeToast]` Appends `<style id="ag-mb-styles">`, mounts `#ag-mb-settings-section`, `#ag-mb-drawer`, and `#ag-mb-toast` (2400ms `setTimeout`), starts a debounced (100ms) `MutationObserver` (`[controls.js:settingsObserver]`) on `#root || document.body`, and attaches a capture-phase outside-tap `pointerdown` listener on `document`.
